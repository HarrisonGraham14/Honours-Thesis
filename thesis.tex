\chapter*{Introduction}\label{s-intro}
\addcontentsline{toc}{chapter}{Introduction}

The goal of this paper is to develop an algorithm for factoring integers using the theory of binary quadratic forms.
The paper is written with the intention of providing motivated explanations to the reader. 

\Cref{s-forms} briefly introduces binary quadratic forms as algebraic objects, and shows that forms of a fixed discriminant can be separated into finitely many equivalence classes.
In \Cref{s-comp}, we derive a binary operation on the equivalence classes, called ``composition'' of forms, to create a finite group (which does not necessarily contain the full set of classes of forms, only those which are ``primitive'').
While the majority of literature simply states an algorithm for composing forms and then proves that it has the desired properties, we opt for a more motivated approach.

The method of factoring derived in \Cref{s-factor} closely follows Daniel Shanks' class group method \cite{shanks}.
The key idea is that we leverage the finite abelian group structure of the class group to search for ``ambiguous forms,'' which immediately lead to factorisations of the discriminant.
We make several alterations to Shanks' method in order to simplify the process without sacrificing the asymptotic growth of the running time of the algorithm, which (with some assumptions) has an expected value of $O(N^{1/4 + \varepsilon})$ for any nonzero $\varepsilon$.

\pagebreak
\chapter{Binary Quadratic Forms}\label{s-forms}

\hspace{-3.5mm}
\textit{
    In this chapter, we establish standard definitions and results on binary quadratic forms,
    as can be found in \cite[Ch.\,1,\,2,\,5]{buchmann}, \cite[Ch.\,1-2]{buell}, \cite[\S\,2]{cox}.
}

\vspace{2mm}
\noindent
A \textbf{binary quadratic form} (or simply a \textbf{form}) is a homogeneous equation of the form
$$f(x, y) = ax^2 + bxy + cy^2.$$
It is called ``binary'' because it is a function of two variables, and ``quadratic'' because the degree of each term is 2.
For our purposes, we are taking $a, b, c \in \Z$, and $x$ and $y$ as integer-valued variables.
Since $x$ and $y$ are variables, the behaviour of a given form is wholly dependent on the values of $a$, $b$ and $c$,
which motivates a shorthand notation of the same form; $(a, b, c)$.
We will impose that $a, c \neq 0$, or else $f$ would be linear in either $x$ or $y$.
Allowing this would serve no purpose beyond complicating proofs with the added work of edge case considerations.

A form is called \textbf{primitive} if $\gcd(a, b, c) = 1$. 
Primitive forms are of primary concern, as the behaviour of a nonprimitive form can be more simply understood by removing the common factor to work with simpler coefficients.


\section{Representation}\label{s-forms-rep}

A form $f(x, y)$ is said to \textbf{represent} an integer $z$ if there exists an integer solution
$$f(x_0, y_0) = z$$
where $x_0, y_0 \in \Z$.
For example, the form $(2, 1, 5)$ (i.e. $f(x, y) = 2x^2 + xy + 5y^2$) represents the number 2, since $f(1, 0) = 2$.
The form does not represent the number 1, though it is not immediately clear how to prove a result of this kind.

The questions which historically motivated the study of forms were as follows \cite[Ch.\,1]{buell};
which numbers can be represented by a given form and, conversely, which forms can represent a given number?
These questions will not be our primary concern, but they will help to motivate the development of the theory that we need.


\pagebreak
\section{Discriminant}\label{s-forms-disc}

It is clear that the form $x^2 + y^2$ exclusively represents non-negative integers. 
The same property holds for the previous example, $2x^2 + xy + 5y^2$, though this is harder to see.
On the other hand, the form $x^2 - y^2$ clearly represents both positive and negative integers.
A reasonable first step to understanding a form's representations is to classify whether they can represent positive, negative, or both positive and negative integers.
To do this, let us consider a related continuous, real-valued function, 
$$g(t) = at^2 + bt + c.$$
Notice that
\begin{align*}
    g\left(\frac{x}{y}\right) &= a\left(\frac{x}{y}\right)^2 + b\left(\frac{x}{y}\right) + c \\
    &= \left(ax^2 + bxy + cy^2\right)\frac{1}{y^2} \\
    &= f(x, y) \frac{1}{y^2}.
\end{align*}
Hence we see that $f(x, y)$ and $g(\tfrac{x}{y})$ have the same sign, with the exception of when $y=0$.
Now, the zeroes of $g(t)$ are given by
$$t = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}.$$
If $b^2 -4ac$ is negative, then $g$ has no real zeroes, meaning that $g$ must be either positive everywhere or negative everywhere (except the origin).
Since $f(x, y)$ agrees with $g(\tfrac{x}{y})$ up to sign, then $f$ must also have a fixed sign for its entire range of outputs - except possibly when $y=0$.
However, note that $f$ can be extended to a continuous function over $\R^2$ and that $f(x, 0) = ax^2$, which can only be zero when $x$ is zero (since $a \neq 0$).
Combining these facts, we can argue that the line $y=0$ must have the same sign as the rest of function, with the exception of the trivial zero.

We call forms satisfying $b^2 -4ac < 0$ \textbf{positive definite} or \textbf{negative definite}, depending on whether they output positive or negative values.
For forms where $b^2 - 4ac > 0$, $g$ has two distinct real zeroes, so $g$ (and hence $f$) will be positive for some inputs and negative for others.
Such forms are called \textbf{indefinite}.
Similar reasoning shows that forms with $b^2 -4ac = 0$, called \textbf{degenerate forms}, are strictly non-negative or non-positive, but such forms are of little interest.

This motivates defining the \textbf{discriminant} of a form $ax^2 + bxy + cy^2$ to be 
$$\Delta = b^2 - 4ac.$$
We will come to see that this classification is far more powerful than simply being able to classify forms as definite or indefinite.

\pagebreak
\begin{lemma}
    The discriminant of a form, $\Delta$, is congruent to 1 or 0 modulo 4. 
\end{lemma}

\begin{proof}
    The definition of the discriminant gives
    $$\Delta \equiv b^2 \pmod{4}$$
    and the only possible values for a perfect square modulo 4 are 1 and 0.
\end{proof}

\begin{lemma}\label{lemma-discriminant-under-multiple}
    If the discriminant of the form $(a, b, c)$ is $\Delta$, then the discriminant of the form $(ak, bk, ck)$ is $\Delta k^2$ (for $k \in \Z$).
\end{lemma}

\begin{proof}
    The discriminant of $(ak, bk, ck)$ is given by
    \[ (bk)^2 - 4(ak)(ck) = b^2k^2 - 4ack^2 = \Delta k^2. \qedhere \]
\end{proof}


\section{Equivalence}\label{s-forms-eq}
Given a form $f(x, y) = ax^2 + bxy + cy^2$, one can find more forms which represent the same set of integers by changing the input space;
take some invertible function $\phi : \Z^2 \rightarrow \Z^2$, and let $g(x, y) = f \circ \phi(x, y)$.
Then for any $x_0, y_0 \in \Z$
$$f(x_0, y_0) = n \implies g(\phi^{-1}(x_0, y_0)) = n$$
$$g(x_0, y_0) = m \implies f(\phi(x_0, y_0)) = m.$$
That is, all integers represented by $f$ are also represented by $g$, and vice versa. 
However, we must also ensure that our choice of $\phi$ gives $g$ to be a form.
Consider the choice $\phi(x, y) = (x+1, y)$.
This is an invertible function on $\Z^2$, but when it is composed with our usual choice of $f$ we have
\begin{align*}
    g(x, y) &= f \circ \phi(x, y) \\
    &= f(x+1, y) \\
    &= a(x+1)^2 + b(x+1)y + cy^2 \\
    &= ax^2 + 2ax + a + bxy + by + cy^2.
\end{align*}
This is no longer a quadratic form, so this choice of $\phi$ should not be allowed. 
Instead, consider a function of the form $\phi(x, y) = (px+qy, rx+sy)$.
This gives
\begin{align*}
    &\hspace{-5mm} g(x, y) = f \circ \phi(x, y) \\
    &= f(px+qy, rx+sy) \\
    &= a(px+qy)^2 + b(px+qy)(rx+sy) + c(rx+sy)^2 \\
    &= \left[ap^2 + bpr + cr^2 \right] x^2
        + \left[ 2apq + b(ps + qr) + 2crs \right] xy
        + \left[ aq^2 + bqs + cs^2 \right] y^2
\end{align*}
which gives $g$ to be a binary quadratic form, as required. 
We require that $\phi$ is invertible so that this is a symmetric relationship.
Note that $\phi$ can be understood as a matrix multiplication
$$\phi \left( \bmat{x \\ y} \right) = \bmat{p & q \\ r & s} \bmat{x \\ y}.$$
So it is clear to see that the valid choices of $\phi$ are the invertible elements of $M_2(\Z)$ --- that is, $\GL_2(\Z)$.
These are the integer matrices with determinant $\pm 1$.
We will often notate the action of $\phi \in GL_2(\Z)$ on a pair of integers
$$\phi(x, y) = x_0, y_0 \hspace{5mm} \text{where} \hspace{5mm} \phi \bmat{x \\ y} = \bmat{x_0 \\ y_0}.$$
We will also sometimes refer to the action of $\phi$ on a form, referring to the form applied to the transformed input coordinates 
$$\phi(f(x, y)) = (f \circ \phi)(x, y) = f(\phi(x, y)).$$

We define forms to be \textbf{improperly equivalent} if there is a $\GL_2(\Z)$ transformation between them.
It is easy to see that this is an equivalence relation.
If we restrict the determinant of the transformation to be strictly positive 1, we split the equivalence classes further ---
we call such forms \textbf{properly equivalent}, which is also an equivalence relation.
This is our standard equivalence for forms, we will write $f \sim g$ to denote $f$ being properly equivalent to $g$.

Let us consider the effect of $\SL_2(\Z)$ transformations on forms.
It is known \cite[\S\,2.4]{buchmann} that a generating set for $\SL_2(\Z)$ is given by
$$S = \bmat{ 0 & -1 \\ 1 & 0 }, \hspace{5mm} T = \bmat{ 1 & 1 \\ 0 & 1}.$$
For $S$, we have
$$S : (a, b, c) \longmapsto (c, -b, a).$$
The discriminant is clearly unchanged by this transformation.
For $T$, we have
$$T : (a, b, c) \longmapsto (a, 2a + b, a + b + c).$$
The discriminant of the resulting form is given by
\begin{align*}
    \Delta &= (2a + b)^2 - 4a(a + b + c) \\
    &= 4a^2 + 4ab + b^2 - 4a^2 - 4ab - 4ac \\
    &= b^2 - 4ac.
\end{align*}
So the discriminant is also unchanged under the action of $T$.
Since all $SL_2(\Z)$ transformations are obtainable by composing $S$ and $T$, and the discriminant is invariant under each component transformation, we have

\vspace{2mm}
\begin{lemma}
    Properly equivalent forms have equal discriminants.
\end{lemma}

\vspace{2mm}
\begin{remark}
    Properly/improperly equivalent forms represent exactly the same set of integers.
\end{remark}

\begin{proof}
    This is by design of our formulation of equivalence.
    Let us now prove it formally.
    We will prove the case of improper equivalence, as any forms which are properly equivalent are also improperly equivalent.

    Suppose $f = (a, b, c)$ and $g = (a', b', c')$ are improperly equivalent forms.
    That is, we have some $\phi \in \GL_2(\Z)$ such that
    $$(f \circ \phi)(x, y) = g(x, y).$$
    If $g$ represents $n$, then there exist integers $x_0, y_0 \in \Z$ such that
    \begin{align*}
        g(x_0, y_0) &= n \\
        \llap{$\implies$} f \circ \phi(x_0, y_0) &= n.
    \end{align*}
    But $\phi$ is a function from $\Z^2 \rightarrow \Z^2$, so we see that $f$ also represents $n$.
    The converse argument, $f$ represents $n$ $\implies$ $g$ represents $n$, is identical.
    Hence, $f$ represents $n$ if and only if $g$ represents $n$.
\end{proof}



\section{Reduction}\label{s-forms-red}
Now that we have an equivalence relation, we would like to be able to find a suitable representative element of a given class.
This will not only prove useful for simplifying computations by choosing a representative with small values of $a$, $b$, and $c$,
but will also give us a method for checking whether two forms belong to the same class by evaluating and comparing their canonical representatives.

We have a generating set for $\SL_2(\Z)$ given by
$$S = \bmat{0 & -1 \\ 1 & 0}, \hspace{5mm} T = \bmat{1 & 1 \\ 0 & 1}.$$
Note that
$$S^4 = I, \hspace{5mm} T^k = \bmat{1 & k \\ 0 & 1}.$$
So we see that any properly equivalent forms must be related by some series of applications of $S$ and $T^k$.
Let us observe the results of these transformations on a generic form $f(x, y) = (a, b, c)$
\begin{align*}
    f \circ S (x, y) &= f \circ \bmat{0 & -1 \\ 1 & 0} \bmat{x \\ y} \\
    &= f(-y, x) \\
    &= a(-y)^2 + b(-y)x + cx^2 \\
    &= ay^2 - bxy + cx^2
\end{align*}
\begin{align*}
    f \circ T^k (x, y) &= f \circ \bmat{1 & k \\ 0 & 1} \bmat{x \\ y} \\
    &= f(x + ky, y) \\
    &= a(x + ky)^2 + b(x + ky)y + cy^2 \\
    &= a(x^2 + 2kxy + k^2y^2) + b(xy + ky^2) + cy^2 \\
    &= ax^2 + (2ak + b)xy + (ak^2 + bk + c)y^2.
\end{align*}
So we have
\begin{gather*}
    S : (a, b, c) \mapsto (c, -b, a) \\
    T^k : (a, b, c) \mapsto (a, 2ak + b, ak^2 + bk + c).
\end{gather*}
Let us use these for constructing a reduction algorithm, which turns any form into a canonical class representative.
For now, we will only consider positive definite forms, as the result is simpler.
Note that in this case, $a$ and $c$ must both be positive, as their signs must be equal for $\Delta = b^2 - 4ac < 0$, and they must be positive to represent positive integers.

A natural way to use $S$ and $T$ to reduce a form is to attempt to minimise $|b|$.
Whenever $|b| > a$, we can use $T$ to reduce $b$ to be in the range $[-a, a]$.
Then, if $c < a$, we can use $S$ to swap $a$ and $c$, then return to step 1 to reduce $b$ further.
Eventually, we reach a form with $|b| \leq a \leq c$, at which point the algorithm terminates.

In the case that $a = |b|$ or $a = c$, a form has two representations which satisfy $a \leq b \leq c$ --- one with positive $b$, and one with negative $b$.
This can be fixed by taking $b$ to be positive in these cases.
We adjust the reduction algorithm such that step 1 moves $b$ into the interval $(-a, a]$ (removing the choice of sign in the case that $|b| = a$), and applying $S$ not only if $a > c$, but if $a = c$ and $b$ is negative.
The full reduction algorithm is as follows

\begin{algorithm}
    \caption{Reduction of positive definite forms} \label{alg-reduction}
    \DontPrintSemicolon
    \vspace{1mm}
    \KwIn{$a, b, c \in \Z$ such that $(a, b, c)$ is a positive definite form.}
    \KwOut{$a, b, c \in \Z$ such that $(a, b, c)$ is reduced and properly equivalent to the provided form.}
    \algosep
    \While {true}{
        $k \gets \lfloor (a - b) / 2a \rfloor$\;
        $c \gets k^2 a + k b + c$\;
        $b \gets 2ka + b$\;
        \If {$a > c$ or $(b < 0$ and $a = c$)}{
            $a \leftrightarrow c$ \hspace{2mm} (swap values)\;
            $b \gets -b$\;
        }
        \If {$|b| \leq a \leq c$ and $((|b| = a $ or $a = c) \implies b \geq 0)$}{
            \Return{$a, b, c$}
        }
    }
\end{algorithm}
\noindent
We say that a positive definite form is \textbf{reduced} if it satisfies
\begin{itemize}
    \item $|b| \leq a \leq c$
    \item $b \geq 0$ if $|b| = a$ or $a = c$.
\end{itemize}

\vspace{2mm}
\begin{theorem}
    \Cref{alg-reduction} terminates in a finite number of steps.
\end{theorem}

\begin{proof}
    On each iteration of the while loop, the value of $|b|$ decreases.
    Since $b$ is initially a finite integer, and only takes on integer values, the initial value of $|b|$ is an upper bound on how many loops the algorithm can perform before terminating.
\end{proof}

\vspace{2mm}
\begin{theorem}
    Every positive definite form is properly equivalent to exactly one reduced form. 
\end{theorem}

\begin{proof}
    The fact that any form is equivalent to at least one reduced form follows immediately from the existence of the reduction algorithm.
    To prove uniqueness, we adapt the proof of Cohen \cite[Prop.\,5.3.3]{cohen}.
    Suppose $f = (a, b, c)$ and $f' = (a', b', c')$ are reduced forms which are properly equivalent.
    That is, there exists a transformation 
    $$\phi = \bmat{p & q \\ r & s} \in \SL_2(\Z).$$
    such that $f \circ \phi = f'$.
    We will show that $f' = f$.

    First, we claim that $a$ is the minimal coefficient of $x^2$ for all forms in its equivalence class --- that is, $a \leq a'$.
    In \Cref{s-forms-eq}, we showed that the result of $\phi$ acting on $f$ is
    $$\left[ap^2 + bpr + cr^2 \right] x^2
        + \left[ 2apq + b(ps + qr) + crs \right] xy
        + \left[ aq^2 + bqs + cs^2 \right] y^2.$$
    That is, $a' = ap^2 + bpr + cr^2$.
    Using the fact that $f$ is reduced, we have $c \geq a$ and $b > -a$.
    Hence, we can bound $a'$;
    $$a' = ap^2 + bpr + cr^2 \geq ap^2 - a|pr| + ar^2$$
    Since $b$ is strictly greater than $-a$, equality can only hold when $pr = 0$.
    Simplifying this result yields
    \begin{align*}
        a' &\geq a \left( |p|^2 - |pr| + |r|^2 \right) \\
        &= a \left( (|p| - |r|)^2 + |pr| \right).
    \end{align*}
    It's impossible for both $pr$ and $|p| - |r|$ to be zero, as this would require $p = r = 0$,
    which would cause the determinant of $\phi$ to be zero.
    But the determinant of $\phi$ is known to be 1, so, since $p, r \in \Z$, we have that $a'$ is at least $a$.

    By the same argument as above (swapping $f$ for $f'$), we also have $a \geq a'$ --- together these results imply $a = a'$.
    That is, properly equivalent reduced forms must have the same leading coefficient.
    
    Now we must show that if $\phi$ fixes $a$, then the action of $\phi$ on $f$ is trivial.
    Recall that in order for the equality $a' = a$ to hold, we must have $pr = 0$.
    This gives
    $$a' = a \left( p^2 + r^2 \right)$$
    So we also require $p^2 + r^2 = 1$.
    This leaves us with two possible cases
    \begin{gather*}
        \textbf{(1)} \hspace{2mm} p = \pm 1, r = 0 \\
        \textbf{(2)} \hspace{2mm} p = 0, r = \pm 1.
    \end{gather*}
    Consider the first case, letting $p = \delta \in \{1, -1\}$.
    Since $\phi \in \SL_2(\Z)$, we have
    $$1 = \text{det}(\phi) = ps - qr = \delta s$$
    which gives $s = \delta$.
    Hence we have
    $$\phi = \bmat{\delta & q \\ 0 & \delta} = \bmat{\delta & 0 \\ 0 & \delta} T^{\delta q}.$$
    Note the action of the matrix
    $$\bmat{-1 & 0 \\ 0 & -1} : (a, b, c) \mapsto (a, b, c)$$
    so $\phi$ has the same action as $T^{\delta q}$. 
    Since this fixes $a$ and shifts $b$ by $2qa$, any choice for $q$ other than 0 (which gives the identity)
    shifts $b$ outside of the range $(-a, a]$, giving a form which is no longer reduced.
    That is, $f' = f \circ \phi = f$.

    In the second case, let $r = \delta \in \{1, -1\}$. 
    The equality $a' = a$ depends on $cr^2 \geq ar^2$ achieving equality. 
    Since $r$ is nonzero and $c \geq a$, this is only achieved if $c = a$.
    Again taking the determinant of $\phi$, we have
    $$1 = \text{det}(\phi) = ps - qr = - \delta q$$
    which gives $q = - \delta$.
    Hence we have
    \begin{align*}
        \phi &= \bmat{0 & - \delta \\ \delta & s} \\ 
        &= \bmat{0 & -1 \\ 1 & 0} \bmat{\delta & 0 \\ 0 & \delta} \bmat{1 & s \\ 0 & 1} \\
        &= S \cdot \bmat{\delta & 0 \\ 0 & \delta} \cdot T^{\delta s}.
    \end{align*}
    As before, we can ignore the action of the negative identity matrix.
    We can also ignore $\delta$, absorbing it into the variable $s$.
    Hence we see that the action of $\phi$ is given by
    $$ST^s : (a, b, a) \mapsto (as^2 + bs + a, - 2as - b, a).$$
    Recall that the leading term must be equal to $a$ in order for this form to be reduced.
    Then we have
    \begin{gather*}
        as^2 + bs + a = a \\
        \implies 0 = as^2 + bs = s(as + b)
    \end{gather*}
    So either $s = 0$ or $as + b = 0$. 
    In the former case, the action of $\phi = S$ flips the sign of the second coefficient.
    If $b \neq 0$, this yields a form that is no longer reduced, and if $b = 0$, it acts trivially.
    
    In the latter case, since $(a, b, a)$ is reduced, we have $a \geq b$ and $|b| \geq 0$.
    To satisfy $as + b = 0$ for $a, b \in \Z$ and $s = \pm 1$, we must therefore have $a = b$, $s = -1$.
    The action of $\phi$ is therefore
    $$\phi : (a, a, a) \mapsto (a, a, a).$$
    Hence we see that the only reduced form which is properly equivalent to $(a, b, c)$ is itself.
\end{proof}

It seems natural to ask, how many reduced forms of a given discriminant exist?
That is, how many equivalence classes of a fixed discriminant are there?
For a reduced form, we have a bound on $b$ given by $|b| \leq a \leq c$.
Hence we can obtain a bound for $b$:
\begin{theorem} \label{theorem-b-bound}
    For a positive definite form $f = (a, b, c)$, if $f$ is reduced, then
    $$|b| \leq \sqrt{-\tfrac{\Delta}{3}}.$$
\end{theorem}
\begin{proof}
    We use the fact that the choices for $a$ and $c$ are constrained by the discriminant:
    \begin{align*}
        b^2 - 4ac &= \Delta \\
        b^2 - 4 \cdot |b| \cdot |b| &\geq \Delta \\
        -3b^2 &\geq \Delta \\
        b^2 &\leq -\tfrac{\Delta}{3} \\
        |b| &\leq \sqrt{-\tfrac{\Delta}{3}} \qedhere
    \end{align*}
\end{proof}
We therefore see that there are only finitely many choices for $b$ in a reduced positive definite form.
If we fix a value of $b$, then can we bound the number of choices for $a$ and $c$?
Consider
\begin{align*}
    b^2 - 4ac &= \Delta \\
    -4ac &= \Delta - b^2 \\
    ac &= \frac{b^2 - \Delta}{4}
\end{align*}
so we have finitely many choices for $a$ and $c$ --- each corresponding to a factorisation of $\tfrac{b^2 - \Delta}{4}$.
Hence, we see that there are only finitely many choices for $a$, $b$, and $c$ when constructing a reduced positive definite form of a fixed discriminant.
We have proved the following for $\Delta < 0$:

\vspace{2mm}
\begin{theorem} \label{theorem-class-number-finite}
    The set of equivalence classes of positive definite forms of fixed discriminant $\Delta$ is finite.
\end{theorem}

\vspace{2mm}
To show this when $\Delta > 0$, we define "reduced" forms differently, with a different reduction algorithm.
Unlike what we have seen for definite forms, this algorithm doesn't terminate at a single reduced class representative, but rather resolves to a cycle of reduced forms.
We won't give the proof for $\Delta > 0$ here, as we do not deal explicitly with indefinite forms in this paper (though the results of \Cref{s-comp} do apply generally).
As such, we will not explicitly construct these results for $\Delta > 0$.
See \cite[\S\,3.1]{buell} for a complete handling of indefinite forms.

\chapter{Composition}\label{s-comp}
\emph{
    This chapter collects algebraic results from various sources as required, though several of the proofs are original.
    The theory of composition of forms is informed by Buell \cite[Ch.\,6-7]{buell} and Buchmann \& Vollmer \cite[Ch.\,7]{buchmann}, though we take our own approach to the derivation.
}

\vspace{2mm}
\noindent
Now that we have seen that there are finitely many equivalence classes of forms of a fixed discriminant, we seek to equip them with a binary operation to form a group.
We achieve this by showing a bijection between classes of forms and classes of ideals, under which the ideal multiplication structure gives a multiplicative structure to the corresponding classes of forms.

\section{Historical Background}
\emph{In this section, we draw from \cite[\S\,2D-\S\,3A]{cox}.}

\vspace{2mm}
\noindent
Legendre was the first to develop a notion of composition, inspired by Lagrange's use of the identity
$$(2x^2 + 2xy + 3y^2) \cdot (2z^2 + 2zw + 3w^2) = (2xz + xw + yz + 3yw)^2 + 5(xw - yz)^2.$$
We see that for any two numbers which can be represented by the form $(2, 2, 3)$, their product can be represented by the form $(1, 0, 5)$.
That is, if we have representations of $n$ and $m$
\begin{gather*}
    2x^2 + 2xy + 3y^2 = n \\
    2z^2 + 2zw + 3w^2 = m
\end{gather*}
then the form $(1, 0, 5)$ represents $nm$ via
$$(2xz + xw + yz + 3yw)^2 + 5(xw - yz)^2 = nm.$$
Legendre sought to generalise results of this kind.
He defined a form $F$ to be a \textbf{composition} of $f$ and $g$ if there exist bilinear forms $B_1$ and $B_2$ such that
\begin{gather*}
    f(x, y) \cdot g(z, w) = F(B_1(x, y; z, w), B_2(x, y; z, w)) \\
    B_i = a_i xz + b_i xw + c_i yz + d_i yw
\end{gather*}
Legendre was able to show that any two forms of the same discriminant can always be composed in this way, but his formulation was multi-valued, giving several options for the resulting form $F$.
This was finally rectified by Gauss in 1801 in his \emph{Disquisitiones Arithmeticae} \cite{gauss}, where he refined Legendre's formulation to turn composition of forms into a well-defined function.
This notion of composition gave a group structure to the set of proper equivalence classes of primitive forms of a fixed discriminant.
This group is called the \textbf{class group}.

As the theory of ideals developed, it became apparent that there exists a bijection between certain classes of ideals of quadratic orders and the class group of quadratic forms \cite[Ch.\,1]{buell}.
This provides us a new and perhaps more intuitive way to derive composition of forms;
we first outline this bijection in \Cref{s-comp-ideals}, then we can leverage the multiplicative structure of ideals to define an analogous operation on forms in \Cref{s-comp-formula}.

Note that this means that we are taking a very different approach to deriving composition of forms than a historical development of the theory would describe.
This has the possible effect of making the connection between forms and ideals seem fairly obvious, when in reality it is quite profound, and the derivations provided here can only exist in retrospect, as the proofs in this paper only make sense to pursue when one already knows that a correspondence exists.
With that said, we hope that the narrative taken here helps the reader to gain an intuitive, geometric understanding of the theory, where many textbooks simply state the result and prove that it has the desired algebraic properties.



\section{Algebraic Number Theory Preliminaries}\label{s-comp-algebraic}
For a finite field extension of the rational numbers, $K/\Q$, an \textbf{order} in $K$ is some subset $\order \subseteq K$ such that \cite[Def.\,4.6.1]{cohen}
\begin{itemize}
    \item $\order$ is a subring of $K$
    \item $\order$ is a finitely generated $\Z$-module
    \item the $\Q$-span of $\order$ is $K$ (i.e. $\text{rank}(\order) = [K:\Q]$)
\end{itemize}
Here, we are working with the definition of a ring that requires the existence of a multiplicative identity.

Now, for $\Delta \equiv 0, 1 \pmod{4}$ where $\Delta$ is not a perfect square, let $K_\Delta = \Q(\sqrt\Delta)$, and define the \textbf{order of discriminant} $\mathbf{\Delta}$ to be 
$$\order_\Delta = \Z + \frac{\Delta + \sqrt\Delta}{2}\Z.$$
One might expect an extension of the integers to take the form $\Z + \sqrt\Delta \Z$, but this ring is not ``integrally closed'' when $\Delta \equiv 1 \pmod{4}$.
If $\Delta$ is square-free (except for a possible factor of 4), the integral closure of $\Q(\sqrt\Delta)$ is $\Z + \frac{1 + \sqrt\Delta}{2}\Z$ (see \cite[Ch.\,1\,\S\,2,\,Exercise\,4]{neukirch}).
As a result, $\order_\Delta$ is a Dedekind domain when $\Delta$ is a ``fundamental discriminant'' \cite[Thm.\,14]{marcus}, which means that ideals of $\order_\Delta$ factorise uniquely into products of prime ideals \cite[Thm.\,16]{marcus}.
The definition of $\order_\Delta$ given is equivalent to
$$\order_\Delta = \begin{cases}
    \Z + \sqrt\Delta \Z & \Delta \equiv 0 \pmod{4} \\
    \Z + \frac{1 + \sqrt\Delta}{2} \Z & \Delta \equiv 1 \pmod{4}
\end{cases}$$
except the chosen definition avoids dealing with multiple cases.

\vspace{2mm}
\begin{lemma}
    $\order_\Delta$ is an order in $K_\Delta$.
\end{lemma}

\begin{proof}
    The latter two conditions of being an order are met by definition, so we need only show that $\order_\Delta$ is a subring of $K_\Delta$. 
    It is also clear that $\order_\Delta \subseteq K_\Delta$, so if we show that $\order_\Delta$ is closed under ring operations, then we can conclude that it is an order in $K_\Delta$.
    Closure under addition is obvious - as for closure under multiplication, let us show closure holds when multiplying the generators of $\order_\Delta$ with themselves, from which closure of all elements under multiplication can be inferred.
    The generators of $\order_\Delta$ are 1 and $\frac{\Delta + \sqrt\Delta}{2}$.
    Closure under multiplication by 1 is obvious, so we need only check
    \begin{align*}
        \frac{\Delta + \sqrt\Delta}{2} \cdot \frac{\Delta + \sqrt\Delta}{2} &= \frac{\Delta^2 + 2\Delta\sqrt\Delta + \Delta}{4} \\
        &= \frac{\Delta - \Delta^2}{4} + \Delta\frac{\Delta + \sqrt\Delta}{2} \\
        &= \frac{\Delta (1 - \Delta)}{4} + \Delta\frac{\Delta + \sqrt\Delta}{2}
    \end{align*}
    and since $\Delta \equiv 0, 1 \pmod{4}$, the first term is an integer, so this result is in $\order_\Delta$.
\end{proof}

\begin{lemma}\label{lemma-ideal-lattice}
    Any nonzero ideal $I \trianglelefteq \order_\Delta$ can be uniquely written in the form
    $$I = l\Z + \frac{m + n\sqrt\Delta}{2}\Z$$
    where $l, m, n$ are integers such that $l, n > 0$, $m \equiv n\Delta \pmod{2}$, and $0 \leq m < 2l$.
\end{lemma}

\begin{proof}
    First, let $l$ be the smallest positive integer in $I$.
    We know that $I$ must contain at least one integer, since for any nonzero $x + \frac{\Delta + \sqrt\Delta}{2}y \in I$, we have 
    $$I \ni x + \Delta y - \frac{\Delta + \sqrt\Delta}{2}y = x + \frac{\Delta - \sqrt\Delta}{2}y.$$
    Since $I$ is an ideal we have
    \begin{align*}
        I &\ni \left( x + \frac{\Delta + \sqrt\Delta}{2}y \right) \left( x + \frac{\Delta - \sqrt\Delta}{2}y \right) \\
        &= \left( x + \frac{\Delta}{2}y \right)^2 -  \left( \frac{\sqrt\Delta}{2}y \right)^2 \\
        &= x^2 + \Delta xy + \frac{\Delta^2 y^2}{4} - \frac{\Delta y^2}{4} \\
        &= x^2 + \Delta xy + \frac{\Delta(\Delta - 1)y^2}{4} \in \Z.
    \end{align*}
    So $I$ has at least one integer, and we can choose $l$ as required.
    Likewise, choose $n$ to be the minimal positive integer such that $x + \frac{\Delta + \sqrt\Delta}{2}n \in I$.
    Since $I$ is closed under addition, we can add multiples of $l$ to this element while staying in $I$.
    For an integer $k$, we have
    $$I \ni kl + x + \frac{\Delta + \sqrt\Delta}{2}n = \frac{(2kl + 2x + n\Delta) + n\sqrt\Delta}{2}.$$
    We can choose $k$ so that
    $$0 \leq 2kl + 2x + n\Delta < 2l.$$
    Set $m = 2kl + 2x + n\Delta$, noting that $m \equiv n\Delta \pmod{2}$.
    Then we have
    $$\frac{m + n\sqrt\Delta}{2} \in I.$$
    Clearly $l\Z + \frac{m + n\sqrt\Delta}{2}\Z \subseteq I$, so we must show the reverse inclusion.
    Consider a general element $z = x + \frac{\Delta + \sqrt\Delta}{2}y \in I$. 
    Note that $n \divides y$, or else by adding multiples of $\frac{m + n\sqrt\Delta}{2}$ to $z$, we can reach an element with a positive coefficient of $\frac{\Delta + \sqrt\Delta}{2}$ that is smaller than $n$, contradicting the choice of $n$.
    Hence, letting $y = y_0 n$, we have
    \begin{align*}
        z &= x + \frac{n\Delta + n\sqrt\Delta}{2}y_0 \\
        &= x + \frac{n\Delta - m}{2}y_0 + \frac{m + n\sqrt\Delta}{2}y_0
    \end{align*}
    Now, we can subtract multiples of $\frac{m + n\sqrt\Delta}{2}$ to get $x + \frac{n\Delta - m}{2}y_0 \in I$. 
    This is an integer, since $m \equiv n\Delta \pmod{2}$, so it must be divisible by $l$, or else we could add a multiple of $l$ to get a positive integer smaller than $l$, a contradiction with the choice of $l$.
    Hence, letting $x + \frac{n\Delta - m}{2}y_0 = lx_0$, we have
    $$z = lx_0 + \frac{m + n\sqrt\Delta}{2}y_0 \in l\Z + \frac{m + n\sqrt\Delta}{2}\Z.$$
    This gives $I \subseteq l\Z + \frac{m + n\sqrt\Delta}{2}\Z$.
    It is clear to see that these are the only possible choices for $l, m,$ and $n$ meeting the required conditions.
\end{proof}

\vspace{2mm}
\begin{lemma}\label{lemma-lattice-divisibility-conditions}
    The $\Z$-module
    $I = l\Z + \frac{m + n\sqrt\Delta}{2}\Z$
    is an ideal of $\order_\Delta$ if and only if the following conditions are met:
    \begin{enumerate}
        \item $n \divides m$
        \item $\frac{m}{n} \equiv \Delta \pmod{2}$
        \item $n \divides l$
        \item $4ln \divides (m^2 - n^2\Delta).$
    \end{enumerate}
\end{lemma}

\begin{proof}
    First, suppose that $I = l\Z + \frac{m + n\sqrt\Delta}{2} \Z$ is an ideal of $\order_\Delta$.
    This means that $I$ is closed under multiplication by elements of $\order_\Delta$.
    In particular,
    \begin{align*}
        l \cdot \frac{\Delta + \sqrt\Delta}{2} &= \left( n\frac{\Delta + \sqrt\Delta}{2} \right) \frac{l}{n} \\
        &= \left( \frac{n\Delta - m}{2} + \frac{m + n\sqrt\Delta}{2} \right) \frac{l}{n} \\
        &= l \cdot \frac{\Delta - m/n}{2} + \frac{m + n\sqrt\Delta}{2} \cdot \frac{l}{n} \in I.
    \end{align*}
    It is clear that $\{l, \frac{m + n\sqrt\Delta}{2} \}$ forms a $\Q$-basis for $\Q(\sqrt\Delta)$, so representation of elements of $\Q(\sqrt\Delta)$ as linear combinations of these basis elements are unique.
    We also know that if an element is in $I$, it has a representation where the coefficients of these elements are integers --- by uniqueness of representation, this is the only choice of coefficients for such an element.
    Hence, we require that the coefficients, $\frac{\Delta - m/n}{2}$ and $\frac{l}{n}$, be integers.
    This immediately implies conditions 1--3.

    Closure of $I$ under multiples from $\order_\Delta$ also gives
    \begin{align*}
        \frac{m + n\sqrt\Delta}{2} \cdot \frac{\Delta + \sqrt\Delta}{2}
        &= \frac{m\Delta + n\Delta}{4} + \frac{(m/n + \Delta)n\sqrt\Delta}{4} \\
        &= \frac{m\Delta + n\Delta}{4} + \frac{(m + n\sqrt\Delta)(m/n + \Delta)}{4} - \frac{m(m/n + \Delta)}{4} \\
        &= \frac{n\Delta - m^2/n}{4} + \frac{m + n\sqrt\Delta}{2} \frac{m/n + \Delta}{2} \\
        &= l \cdot - \frac{m^2 - n^2\Delta}{4ln} + \frac{m + n\sqrt\Delta}{2} \cdot \frac{m/n + \Delta}{2}
    \end{align*}
    Again, we require the coefficients to be integers, which gives condition 4.

    Conversely, let $I = l\Z + \frac{m + n\sqrt\Delta}{2}\Z$ satisfy conditions 1--4.
    Since $I$ is a $\Z$-module, it is closed under addition and under multiplication by integers.
    By the calculations above, we see that the given divisibility conditions are sufficient for $l$ and $\frac{m + n\sqrt\Delta}{2}$ to remain in $I$ when multiplied by $\frac{\Delta + \sqrt\Delta}{2}$.
    Hence, a generic product of elements in $I$ and $\order_\Delta$ is
    \begin{align*}
        &\hspace{-5mm} \left( lx + \frac{m + n\sqrt\Delta}{2}y \right) \cdot \left( x' + \frac{\Delta + \sqrt\Delta}{2} y' \right) \rnote{x, x', y, y' \in \Z} \\
        &= lxx' + \frac{m + n\sqrt\Delta}{2} yx' + l \frac{\Delta + \sqrt\Delta}{2} xy' + \frac{m + n\sqrt\Delta}{2} \frac{\Delta + \sqrt\Delta}{2} yy'.
    \end{align*}
    Each term is in $I$, so their sum is in $I$. 
    Hence, $I$ is an ideal of $\order_\Delta$.
\end{proof}

We also need to define the norm of an ideal.
For a nonzero ideal $I \trianglelefteq \order_\Delta$, the \textbf{norm} is defined as
$$N(I) = \left| \order_\Delta / I \right|.$$

\vspace{2mm}
\begin{lemma}\label{lemma-ideal-norm}
    The norm of $I = l\Z + \frac{m + n\sqrt\Delta}{2} \Z \trianglelefteq \order_\Delta$ is given by
    $$ N(I) = ln .$$
\end{lemma}

\begin{proof}
    Consider the elements of the quotient $\order_\Delta / I$.
    Claim that these are given by
    $$\order_\Delta / I = \left\{ x + \frac{\Delta + \sqrt\Delta}{2}y \mathrel{:} 0 \leq x < l, \hspace{2mm} 0 \leq y < n \right\}.$$
    To see that this is the correct formulation, consider a generic element 
    $$z = x + \frac{\Delta + \sqrt\Delta}{2}y \in \order_\Delta.$$
    By first subtracting multiples of $\frac{m + n\sqrt\Delta}{2}$, we can write
    $$z \sim x' + \frac{\Delta + \sqrt\Delta}{2}y' \rnote{0 \leq y' < n.}$$
    Next, by subtracting multiples of $l$, we get
    $$z \sim x'' + y'\frac{\Delta + \sqrt\Delta}{2} \rnote{0 \leq x'' < l.}$$
    So every element is represented by the given cosets.
    None of these cosets can be equal, since adding any multiple of $l$ would force the integer part outside of the allowed range, which cannot be rectified by adding a multiple of $\frac{m + n\sqrt\Delta}{2}$, or else the coefficient of $\frac{\Delta + \sqrt\Delta}{2}$ would be forced outside of the allowed range.
\end{proof}

Finally, we will define the norm of an element of a number field.
This can be defined more generally for larger fields \cite[\S\,3.2]{jarvis}, but for our purposes, we will only handle the quadratic case.
For any quadratic number field $K$ (that is, $K = \Q(\sqrt{\Delta})$ where $\Delta$ is not a perfect square), the \textbf{norm of an element} $x + y\sqrt\Delta \in K$ (where $x, y \in \Q$) is given by \cite[\S\,6.2]{buell}
$$N(x + y\sqrt\Delta) = (x + y\sqrt\Delta) \cdot (x - y\sqrt\Delta) = x^2 - y^2\Delta.$$
This can be positive or negative, and is zero if and only if $x = y = 0$, since $\Delta$ is not a perfect square.

\hspace{2mm}
\begin{lemma}
    The norms of elements are multiplicative.
    That is,
    $$N(\alpha \beta) = N(\alpha)N(\beta) \rnote{\forall \alpha, \beta \in \order_\Delta.}$$
\end{lemma}
\begin{proof}
    Let $x_1, x_2, y_1, y_2 \in \Q$.
    Then we have
    \begin{align*}
        N((x_1 + y_1\sqrt\Delta)(x_2 + y_2\sqrt\Delta)) &= N(x_1x_2 + y_1y_2\Delta + (x_1y_2 + x_2y_1)\sqrt\Delta) \\
        &= (x_1x_2 + y_1y_2\Delta)^2 - (x_1y_2 + x_2y_1)^2 \Delta \\
        &= x_1^2 x_2^2 - x_1^2 y_2^2 \Delta - x_2^2 y_1^2 \Delta + y_1^2 y_2^2 \Delta^2 \\
        &= (x_1^2 - y_1^2\Delta)(x_2^2 - y_2^2\Delta) \\
        &= N(x_1 + y_1\sqrt\Delta)N(x_2 + y_2\sqrt\Delta). \qedhere
    \end{align*}
\end{proof}

\noindent
There exists a similar result for the norms of ideals, although with a condition.
First, define an \textbf{invertible ideal} of $\order_\Delta$ to be an ideal $I \in \order_\Delta$ such that there is some ideal $I' \in \order_\Delta$ for which $II'$ is principal 
(this is technically the definition of an invertible \emph{fractional} ideal \cite[Prop.\,8.4.11]{buchmann}, but we have avoided discussing fractional ideals for simplicity).
Now we can state:

\vspace{2mm}
\begin{lemma} \label{invertible-norm-multiplicative}
    If $I$ and $I'$ are ideals of $\order_\Delta$ and $I$ is invertible, then
    $$N(II') = N(I)N(I').$$
\end{lemma}
\noindent
A proof of this is given by \cite[Prop.\,4.6.8]{cohen}.

\vspace{2mm}
\begin{lemma} \label{lemma-norm-relation}
    For any nonzero $\alpha \in \order_\Delta$, we have
    $$N(\langle \alpha \rangle) = \left| N(\alpha) \right|.$$
\end{lemma}
\noindent
A proof of this is given by \cite[Exercise 7.14-7.15]{cox}.



\pagebreak
\section{Ideal Correspondence}\label{s-comp-ideals}
We now seek to use the findings of \Cref{s-comp-algebraic} to develop a notion of equivalence between ideals of $\order_\Delta$ and binary quadratic forms of discriminant $\Delta$.
To do this, consider an ideal $I = l\Z + \frac{m + n\sqrt\Delta}{2}\Z \trianglelefteq \order_\Delta$, where $l, n > 0$ and $0 \leq m < 2l$.
The norm of a general element of $I$ is given by
\begin{align*}
    \hspace{-5mm} N\left(lx + \frac{m + n\sqrt\Delta}{2}y\right)
    &= \left( lx + \frac{m}{2}y \right)^2 - \left(\frac{n\sqrt\Delta y}{2} \right)^2  \\
    &= l^2x^2 + lmxy + \frac{m^2 - n^2\Delta}{4}y^2 
    \stepcounter{equation}\tag{\theequation}\label{eq-ideal-norm-form}
\end{align*}
This is a binary quadratic form.
The discriminant of this form is given by
$$(lm)^2 - 4 \cdot l^2 \cdot \frac{m^2 - n^2\Delta}{4} = (ln)^2\Delta.$$
By \Cref{lemma-discriminant-under-multiple}, if we can divide the form by $N(I) = ln$, we will arrive at a form of discriminant $\Delta$.
That is,
$$\frac{N \left( lx + \frac{m + n\sqrt\Delta}{2}y \right)}{N \left( I \right)} = \frac{l}{n}x^2 + \frac{m}{n}xy + \frac{m^2 - n^2\Delta}{4ln}y^2.$$
The divisibility conditions of \Cref{lemma-lattice-divisibility-conditions} show each coefficient to be an integer, hence this is a binary quadratic form of discriminant $\Delta$.
We can therefore define a function $\Theta$ from ideals of $\order_\Delta$ to forms of discriminant $\Delta$:
$$\Theta : l\Z + \frac{m + n\sqrt\Delta}{2}\Z \longmapsto \left( \frac{l}{n}, \frac{m}{n}, \frac{m^2 - n^2\Delta}{4ln} \right).$$
We want a map which is invertible, so that we can take forms to corresponding ideals, multiply the ideals, then transform the resulting ideal back into a form, inducing a binary operation on forms.
To achieve this, we quotient the domain and codomain into equivalence classes.
Defining ideals of $\order_\Delta$ to be \textbf{narrowly equivalent} if they differ by a scalar multiple in $\Q(\sqrt\Delta)$ of positive norm, we have:

\hspace{2mm}
\begin{theorem} \label{thm-ideal-correspondence}
    The map $\Theta$ induces a bijection, $\bar{\Theta}$, between narrow equivalence classes of ideals of $\order_\Delta$ and proper equivalence classes of forms of discriminant $\Delta$.
\end{theorem}
\hspace{2mm}

The choice of the definition of narrow equivalence may initially seem arbitrary; 
we will spend the remainder of this section motivating this definition and proving that it yields the desired correspondence to classes of forms.

\pagebreak
First, note that the choice of canonical bases for ideals, while computationally convenient, is arbitrary.
What if we choose a different basis for $I = l\Z + \frac{m + n\sqrt\Delta}{2}\Z$?
A transformation from the canonical basis to our new basis is given by some matrix $\phi \in \GL_2(\Z)$.
If $|\det(\phi)| = -1$, we can multiply $\phi$ by the matrix 
$\left[ \begin{smallmatrix} 0 & 1 \\ 1 & 0 \end{smallmatrix} \right]$, 
which corresponds to reordering the basis elements, to get a matrix in $\SL_2(\Z)$.
Let us therefore say $\phi \in \SL_2(\Z)$.
What happens if we take the norm of a generic element expressed with this new basis? 
Would we have reached a different formulation of $\Theta$?
A general element of $I$ as a sum of the new basis is
$$\left( \phi \bmat{l \\ \frac{m + n\sqrt\Delta}{2}} \right) \cdot \bmat{x \\ y}.$$
The norm of such an element is given by
\begin{align*}
    N \left( \left( \phi \bmat{l \\ \frac{m + n\sqrt\Delta}{2}} \right) \cdot \bmat{x \\ y} \right)
    &= N \left( \bmat{l & \frac{m + n\sqrt\Delta}{2}} \phi^T \bmat{x \\ y} \right) \\
    &= N \left( lx_0 + \frac{m + n\sqrt\Delta}{2} y_0 \right)
\end{align*}
where $x_0$ and $y_0$ are linear sums of $x$ and $y$ given by
$$\phi^T \bmat{x \\ y} = \bmat{x_0 \\ y_0}.$$
So the form we would derive with this new basis is
$$\frac{l}{n}x_0^2 + \frac{m}{n}x_0y_0 + \frac{m^2 - n^2\Delta}{4ln} y_0^2 = \phi^T \left( \frac{l}{n}x^2 + \frac{m}{n}xy + \frac{m^2 - n^2\Delta}{4ln} y^2 \right).$$
This is properly equivalent to the form that we found when using our canonical basis.
We already had the sense that properly equivalent forms contain the same data, since they represent the same numbers.
We now have a new way of thinking of this --- equivalent forms describe the norms of elements of the same ideal using different bases.

If we now allow any basis to be chosen to represent an ideal, a bijection induced by $\bar{\Theta}$ must necessarily map into equivalence classes of forms ---
since $\bar{\Theta}(I)$ maps into different (but equivalent) forms depending on the choice of basis.
By taking the codomain to be proper equivalence classes of forms, the function remains well defined.

When choosing a basis for $I$, there exists a $\GL_2(\Z)$ transformation $\phi$ from the canonical basis to the chosen basis.
If $\phi \notin \SL_2(\Z)$ (i.e. $\det(\phi) = -1$), then we can compose $\phi$ with the matrix 
$$\bmat{0 & 1 \\ 1 & 0} : \bmat{x \\ y} \longmapsto \bmat{y \\ x}$$
to get a $\SL_2(\Z)$ transformation which gives the same basis in the reversed order.
So given a basis for $I$, how do we determine the ``correct'' ordering of elements?
Consider that for bases $B_1 = \{ l, \frac{m + n\sqrt\Delta}{2} \}$ and $B_2 = \{ \alpha_1 + \alpha_2 \sqrt\Delta , \beta_1 + \beta_2 \sqrt\Delta \}$, 
we have the following matrices for converting coefficients on the basis elements into coefficients on $1$ and $\sqrt\Delta$, respectively:
$$\phi_1 = \bmat{l & \frac{m}{2} \\ 0 & \frac{n}{2}}, 
\hspace{10mm} 
\phi_2 = \bmat{\alpha_1 & \beta_1 \\ \alpha_2 & \beta_2}.$$
Taking $\phi \in \GL_2(\Z)$ to be the change of basis matrix from $B_1$ to $B_2$, we have
$$\phi = \phi_2^{-1} \circ \phi_1$$
so the condition for $\phi \in \SL_2(\Z)$ is
$$\det \left( \phi \right) = \det \left( \phi_2^{-1} \circ \phi_1 \right) = \det \left( \phi_2 \right)^{-1} \cdot \det \left( \phi_1 \right) = 1.$$
The determinant of $\phi_1$ is $\frac{ln}{2}$, which is positive since $l$ and $n$ are defined to be strictly positive.
Therefore, it is sufficient to check that the determinant of $\phi_2$ is positive.
We have therefore shown

\vspace{2mm}
\begin{lemma} \label{lemma-basis-orientation}
    For an ideal $I \trianglelefteq \order_\Delta$ with a basis $\{ \alpha_1 + \alpha_2 \sqrt\Delta , \beta_1 + \beta_2 \sqrt\Delta \}$ such that $\alpha_1 \beta_2 - \alpha_2 \beta_1 > 0$, we have a proper equivalence of forms
    $$\Theta(I) \sim \frac{N \left( (\alpha_1 + \alpha_2 \sqrt\Delta)x + (\beta_1 + \beta_2 \sqrt\Delta)y \right) }{N(I)}.$$
\end{lemma}
\vspace{2mm}

We must now take equivalence classes of the domain of $\Theta$ so that we get an injective function.
Note the effect of taking an integer multiple of an ideal.
In particular, consider $kI = kl\Z + k\frac{m + n\sqrt\Delta}{2}\Z$, where $k$ is a nonzero integer.
The corresponding form is
$$\Theta(kI) = \left( \frac{kl}{kn}, \frac{km}{kn}, \frac{k^2m^2 - k^2n^2\Delta}{4k^2ln} \right) = \left( \frac{l}{n}, \frac{m}{n}, \frac{m^2 - n^2\Delta}{4ln} \right) = \Theta(I).$$
So $\Theta$ maps ideals which vary by an integer multiple to the same form.
What about ideals which vary by a constant multiple which isn't necessarily rational?
Let $I = l\Z + \frac{m + n\sqrt\Delta}{2}\Z$ and $\alpha \in \order_\Delta$.
Then a $\Z$-basis for $\alpha I$ is 
$$\left\{\alpha l, \hspace{2mm} \alpha \frac{m + n\sqrt\Delta}{2}\right\}$$
and a generic element of this ideal is $\alpha l x + \alpha \frac{m + n\sqrt\Delta}{2} y$.
A form corresponding to this ideal is given by
\begin{align*}
    \Theta(\alpha I) &= \frac{N \left( \alpha l x + \alpha \frac{m + n\sqrt\Delta}{2} y \right)}{N(\alpha I)} \\
    &= \frac{N \left(\alpha \cdot \left( l x + \frac{m + n\sqrt\Delta}{2} y \right) \right)}{N(\langle \alpha \rangle \cdot I)} \\
    &= \frac{N(\alpha)}{N(\langle \alpha \rangle)} \cdot \frac{N \left( l x + \frac{m + n\sqrt\Delta}{2} y \right) }{N(I)} \\
    &= \frac{N(\alpha)}{\left| N(\alpha) \right|} \cdot \Theta(I).
\end{align*}
Here, we have used \Cref{lemma-norm-relation}, since principal ideals are clearly invertible (via multiplication by any other principal ideal).
So $I$ and $\alpha I$ are mapped to the same form so long as $N(\alpha) > 0$.
We therefore desire that such forms be equivalent so that $\bar{\Theta}$ may be injective --- but we must be careful when formalising the equivalence relation.
We cannot simply say that ideals are equivalent if they vary by a positive-norm scalar multiple in $\order_\Delta$, as this would not be a transitive relation;
we would have $I \sim 2I$ and $I \sim 3I$, but $2I \nsim 3I$, since $\frac{2}{3} \notin \order_\Delta$.
So it is clear that we should allow $\alpha$ to be in the field of fractions of $\order_\Delta$, which is $\Q(\sqrt\Delta)$.
This provides a motivation for the definition of narrow equivalence of ideals.

To show that $\bar{\Theta}$ is a bijection, we will construct its inverse.
A natural candidate resembling an inverse of $\Theta$ is
$$\Psi : (a, b, c) \longmapsto a\Z + \frac{b + \sqrt\Delta}{2}\Z.$$
We assume that $a$ is positive in order to preserve the basis orientation condition.
For indefinite forms, $a$ may be negative, but we can always find an equivalent form where $a > 0$.
Of course, $\Psi$ is not an inverse to $\Theta$, which is not injective and therefore has no inverse.
However, we will show that $\Psi$ induces an inverse function to $\bar{\Theta}$.

First, we must show that $\Psi$ is well defined --- 
that is, that the output truly is an ideal of $\order_\Delta$.
We show this using \Cref{lemma-lattice-divisibility-conditions}.
Conditions 1 and 3 are trivial, since we have chosen $n = 1$, while conditions 2 and 4 are enforced by $\Delta = b^2 - 4ac$.
We have hence shown that $\Psi$ is well-defined.

Now, we will show that $\Psi$ induces a function $\bar{\Psi}$ from proper equivalence classes of forms to narrow equivalence classes of ideals.
To do this, we must show that $\bar{\Psi}$ is well defined by showing that $\Psi$ takes equivalent forms to equivalent ideals.
First, observe where $\Psi$ maps the form $f = (a, b, c)$ after a $T$-transformation:
\begin{align*}
    \Psi : (a, b + 2a, c + b + a) &\mapsto a\Z + \frac{b + 2a + \sqrt\Delta}{2}\Z \\
    &= a\Z + \frac{b + \sqrt\Delta}{2}\Z.
\end{align*}
Next, observe where it sends $f$ after an $S$-transformation:
\begin{align*}
    \Psi : (c, -b, a) &\mapsto c\Z + \frac{- b + \sqrt\Delta}{2}\Z \\
    &\sim \frac{b + \sqrt\Delta}{2} \left( c\Z + \frac{- b + \sqrt\Delta}{2}\Z \right) \\
    &= c \frac{b + \sqrt\Delta}{2} \Z + \frac{\Delta - b^2}{4}\Z  \\
    &= c \frac{b + \sqrt\Delta}{2} \Z - \frac{4ac}{4}\Z  \\
    &= c \left( \frac{b + \sqrt\Delta}{2} \Z + a\Z \right) \\
    &\sim a\Z + \frac{b + \sqrt\Delta}{2}\Z.
\end{align*}  
So applying an $S$ or $T$ transformation to a form doesn't change the class of ideals that it is sent to by $\Psi$ --- 
and since all $\SL_2(\Z)$ transformations are compositions of $S$ and $T$, we conclude that $\bar{\Psi}$ is well-defined.

Finally, we are ready to prove \Cref{thm-ideal-correspondence} by showing that $\bar{\Psi}$ is an inverse function to $\bar{\Theta}$.

\begin{proof}[Proof of \Cref{thm-ideal-correspondence}]
First we show $\bar{\Theta} \circ \bar{\Psi}$ is the identity by considering its action on a generic class of forms $\bar{f}$.
Let $f = (a, b, c)$ be a representative of $\bar{f}$, chosen such that $a > 0$.
\begin{align*}
    \bar{\Theta} \circ \bar{\Psi} ((a, b, c)) &= \bar{\Theta} \left( a\Z + \frac{b + \sqrt\Delta}{2} \Z \right) \\
    &= (a, b, c) = f.
\end{align*}
Likewise, for any narrow ideal class $\bar{I}$, choose a class representative with canonical representation $I = l\Z + \frac{m + n\sqrt\Delta}{2}\Z$. 
Then we have
\begin{align*}
    \bar{\Psi} \circ \bar{\Theta} \left( l\Z + \frac{m + n\sqrt\Delta}{2}\Z \right) 
    &= \bar{\Psi} \left( \left( \frac{l}{n}, \frac{m}{n}, \frac{m^2 - n^2\Delta}{4ln} \right) \right) \\
    &= \frac{l}{n}\Z + \frac{m/n + \sqrt\Delta}{2} \Z \\
    &\sim n \cdot \left( \frac{l}{n}\Z + \frac{m/n + \sqrt\Delta}{2} \Z \right) = I.
\end{align*}
Hence, $\bar{\Psi}$ is an inverse to $\bar{\Theta}$, which means that these functions are bijections between proper equivalence classes of forms and narrow equivalence classes of ideals.
\end{proof}

\section{Composition Formula}\label{s-comp-formula}

Having seen that forms of the same discriminant correspond to ideals of the same ring, 
we now seek to find a general formula for an operation corresponding to ideal multiplication.
First, consider ideals $I, I' \trianglelefteq \order_\Delta$.
In general, equivalent ideals to these take the form $\alpha I$ and $\alpha' I'$, respectively, where $\alpha, \alpha' \in \Q(\sqrt\Delta)$.
The product of these equivalent ideals is
$$\alpha I \cdot \alpha' I' = \alpha \alpha' \cdot I I'$$
which is narrowly equivalent to the ideal $II'$.
Hence we see that ideal multiplication is a well-defined operation on narrow equivalence classes.
This gives us a semigroup of narrow equivalence classes, which can be turned into a group if we restrict to classes of invertible ideals.
We can hence use this to induce a group operation on proper equivalence classes of forms which correspond to invertible ideals.

\begin{theorem} \label{thm-invertible-primitive}
    Let $f$ be a form and $I$ be an ideal such that $\Theta(I) = f$. Then $I$ is invertible if and only if $f$ is primitive.
\end{theorem}

\begin{proof}
    Consider a form $f = (a, b, c)$.
    The corresponding ideal is $I = a\Z + \frac{b + \sqrt\Delta}{2}\Z$.
    A natural candidate for an ideal $I'$ such that $II'$ is principal would be to take the conjugate of $I$ in hopes that the generators cancel nicely.
    Letting $I' = a\Z + \frac{b - \sqrt\Delta}{2}\Z$, we have
    \begin{align*}
        II' &= \left( a\Z + \frac{b + \sqrt\Delta}{2}\Z \right) \left( a\Z + \frac{b - \sqrt\Delta}{2}\Z \right) \\
        &= a^2\Z + a\frac{b + \sqrt\Delta}{2}\Z + a\frac{b - \sqrt\Delta}{2}\Z + \frac{b^2 - \Delta}{4}\Z \\
        &= a^2\Z + a\frac{b + \sqrt\Delta}{2}\Z + a\frac{2b}{2}\Z + \frac{b^2 - b^2 + 4ac}{4}\Z \\
        &= a(a\Z + b\Z + c\Z) + a\frac{b + \sqrt\Delta}{2}\Z
    \end{align*}
    If $f$ is primitive, then $\gcd(a, b, c) = 1$, so we have
    $$II' = a \left( \Z + \frac{b + \sqrt\Delta}{2}\Z \right) = a \order_\Delta = \langle a \rangle.$$
    So $I$ is invertible. If $f$ is not primitive, we have
    $$II' = a \left( \gcd(a, b, c) \Z + \frac{b + \sqrt\Delta}{2}\Z \right).$$
    To prove that this cannot be principal, we use \Cref{lemma-ideal-lattice} to find
    $$N(II') = a^2 \cdot \gcd(a, b, c), \hspace{5mm} N(I) = a, \hspace{5mm} N(I') = a.$$
    That is, $N(II') \neq N(I)N(I')$.
    So by \Cref{invertible-norm-multiplicative}, $I$ cannot be invertible.
\end{proof}

So we seek to induce a group operation on classes of primitive forms of fixed discriminant.
Let $f = (a, b, c)$ and $g = (a', b', c')$ be primitive forms of discriminant $\Delta$ where $a$ and $a'$ are positive.
These correspond to invertible ideals of $\order_\Delta$:
$$I_f = a\Z + \frac{b + \sqrt\Delta}{2}\Z, \hspace{5mm} I_g = a'\Z + \frac{b' + \sqrt\Delta}{2}\Z.$$
The product of these ideals is given by
$$I = I_f \cdot I_g = aa'\Z + a\frac{b' + \sqrt\Delta}{2}\Z + a'\frac{b + \sqrt\Delta}{2}\Z + \frac{bb' + \Delta + (b + b')\sqrt\Delta}{4}\Z.$$
By \Cref{lemma-ideal-lattice}, we can express this product in the form $l\Z + \frac{m + n\sqrt\Delta}{2}\Z$. 
We know that $n$ is the minimal positive coefficient of $\frac{\sqrt\Delta}{2}$ among elements of $I$, so we have
$$n = \gcd\left(a, a', \frac{b+b'}{2}\right)$$
noting that we will always take the gcd to be positive. 
Also note that $\frac{b + b'}{2}$ is an integer, since $b$ and $b'$ are both congruent to $\Delta$ mod 2.
Using B\'ezout's identity, there exist $u, v, w \in \Z$ such that
$$au + a'v + \frac{b+b'}{2}w = n.$$
These allow us to find an element of $I$ which satisfies the minimal condition on $n$:
\begin{align*}
    &\hspace{-5mm} a\frac{b' + \sqrt\Delta}{2}u + a'\frac{b + \sqrt\Delta}{2}v + \frac{bb' + \Delta + (b + b')\sqrt\Delta}{4}w \\
    &= \frac{ab'u + a'bv + \frac{bb' + \Delta}{2}w + n\sqrt\Delta}{2}
\end{align*}
Hence,
$$m = ab'u + a'bv + \frac{bb' + \Delta}{2}w.$$
Note that this isn't necessarily our canonical choice for $m$, since we haven't added a multiple of $l$ to enforce $0 \leq m < 2l$, but the ideal is unchanged by this choice.
Different choices for $m$ (which can arise by different choices for B\'ezout coefficients $u, v,$ and $w$) simply correspond to a different basis for the ideal, so we will find a different, but equivalent form.

We can find $l$ by considering the norms of ideals.
The norm of $I_f$ is $a$, and the norm of $I_g$ is $a'$, and each of these ideals are invertible, since they correspond to reduced forms.
Hence, by \Cref{invertible-norm-multiplicative} the norm of $I$ must be $aa'$.
But by \Cref{lemma-ideal-norm}, we have
\begin{gather*}
    aa' = N(I) = ln \\
    \implies l = \frac{aa'}{n}
\end{gather*}
Hence, with the given choices of $m$ and $n$, the form corresponding to the resulting ideal is
$$(a, b, c) \cdot (a', b', c') = \left( \frac{aa'}{n^2}, \frac{m}{n}, \frac{m^2 - n^2\Delta}{4aa'} \right).$$
By the divisibility conditions of \Cref{lemma-lattice-divisibility-conditions} applied to $I$ and $I'$, we can see that each term of the resulting form is an integer.
We have derived the following algorithm:
\begin{algorithm}
    \caption{Composition formula} \label{alg-composition}
    \DontPrintSemicolon
    \vspace{1mm}
    \KwIn{$a, b, c, a', b', c' \in \Z$ such that $(a, b, c)$ and $(a', b', c')$ are reduced forms with a common discriminant.}
    \KwOut{$a, b, c \in \Z$ such that $(a, b, c)$ is the composition of the given forms.}
    \algosep
    $\Delta \gets b^2 - 4ac$\;
    $B \gets (b + b')/2$\;

    \vspace{2mm}
    Choose $u, v, w, n \in \Z$ such that $ua + va' + wB = n = \gcd(a, a', B)$ ---
    this can be computed using two applications of Euclid's extended algorithm \cite[\S\,1.3.2]{cohen}, first computing the gcd of $a$ and $a'$, then the gcd of the result and $B$.\;
    \vspace{2mm}

    $\displaystyle m \gets ab'u + a'bv + \frac{bb' + \Delta}{2}w$\;
    \vspace{2mm}

    \Return{$\displaystyle\frac{aa'}{n^2}, \frac{m}{n}, \frac{m^2 - n^2\Delta}{4aa'}$}
    \vspace{1mm}
\end{algorithm}

\noindent
Optimisations to this algorithm are given by Cohen \cite[Alg.\,5.4.7]{cohen}.

\section{Identity and Inverses}\label{s-comp-idinv}
Now that we have a well defined binary operation on classes of forms, we seek to find an identity element and inverses.
The identity of ideal classes is given by ideals which multiply others without affecting their equivalence class - that is, the class of principal forms.
One such ideal is $\langle 1 \rangle = \order_\Delta$.
The corresponding form is
$$\Theta(\order_\Delta) = \Theta \left( 1\Z + 1\frac{\Delta + \sqrt\Delta}{2} \right) = \left(1, \Delta, \frac{\Delta^2 - \Delta}{4} \right).$$
By applying a $T$ transformation, we get the reduced \textbf{principal form}:
$$\text{id}_\Delta = \begin{cases}
    \left( 1, 0, \frac{-\Delta}{4} \right) & \Delta \equiv 0 \pmod{4} \\
    \left( 1, 1, \frac{1 - \Delta}{4} \right) & \Delta \equiv 1 \pmod{4}
\end{cases}$$

Now, consider a primitive form $f = (a, b, c)$, which has the corresponding ideal $I = a\Z + \frac{b + \Delta}{2}\Z$.
We saw in the proof of \Cref{thm-invertible-primitive} that the inverse of this ideal class is given by
$$I' = a\Z + \frac{b - \sqrt\Delta}{2}\Z = I = a\Z + \frac{-b + \sqrt\Delta}{2}\Z.$$
The form corresponding to this ideal is $\Theta(I') = (a, -b, c)$.

We now know that there are finitely many proper equivalence classes of fixed discriminant $\Delta$ (\Cref{theorem-class-number-finite}), that composition is a well-defined binary operation on this set, that there is an identity class which acts trivially on other classes, and that each class has an inverse.
We also have closure under the operation of composition, since the product of invertible ideals is clearly invertible (if $I$ is inverted by $I'$ and $J$ is inverted by $J'$, then $IJ$ is inverted by $I'J'$).
Hence, the set of classes of primitive forms of fixed discriminant $\Delta$ form a finite group under the operation of composition.
We call this the \textbf{class group}, denoted $\Cl_\Delta$.

\chapter{Factoring}\label{s-factor}
\emph{
    This chapter follows a factoring method outlined by Daniel Shanks \cite{shanks}.
    We take each of the components of his factoring algorithm, and adapt them to develop a similar, arguably simpler algorithm.
}

\vspace{2mm}
\noindent
A key practical application of number theory is the factoring algorithms that its theory allows.
Integer factorisation is a deceptively difficult task to perform efficiently.
As a baseline for comparison, let us consider the most elementary factoring algorithm - trial division.

\begin{algorithm}
    \caption{Factoring by trial division}
    \DontPrintSemicolon
    \vspace{1mm}
    \KwIn{$n \in \Z$ where $n$ is composite.}
    \KwOut{$x \in \Z$ where $x$ is a nontrivial factor of $n$ (if such a factor exists).}
    \algosep
    $n \gets |n|$\;
    $x \gets 2$\;
    \While {$x \leq \sqrt{n}$}{
        \eIf {$n \equiv 0 \pmod{x}$}{
            \Return{$x$}
        }{
            $x \gets x + 1$\;
        }
    }
\end{algorithm}
\noindent
We will use big-$O$ notation to analyse the complexity of algorithms.
Trial division has a complexity of $O(\sqrt{n})$ arithmetic operations.
If one considers the complexity not as a function of the size of the number being factored, but instead by the length of its binary representation,
we have that trial division scales exponentially with the length of the input that we are trying to factor.
For this reason, such an algorithm will sometimes be called \textbf{exponential} in some contexts.


\section{Ambiguous forms}\label{s-factor-amb}
The key insight which bridges the theory of binary quadratic forms into the realm of factoring comes from considering forms of order 2 - that is, forms which are their own inverses. 
Such forms are called \textbf{ambiguous forms}.

\vspace{2mm}
\begin{lemma}
    A reduced form $f$ is ambiguous if and only if it meets one of the following conditions:
    \begin{align*}
        &\textbf{(1)} \hspace{2mm} b = 0 \implies f = (a, 0, c) \\
        &\textbf{(2)} \hspace{2mm} a = b \implies f = (a, a, c) \\
        &\textbf{(3)} \hspace{2mm} a = c \implies f = (a, b, a).
    \end{align*}
\end{lemma}

\begin{proof}
    For a reduced form to be properly equivalent to its inverse, we have
    $$(a, b, c) \equiv (a, -b, c).$$
    When is this possible?
    The clearest case where the equality holds is when $b = 0$, but there are other possibilities.
    If $b \neq 0$, the only way for the equivalence to hold is if $(a, -b, c)$ is not fully reduced.
    Since $(a, b, c)$ is reduced, we know that $|b| \leq a \leq c$, 
    so the only way for $(a, -b, c)$ not to be reduced is if $-b < 0$ and $a = |-b|$ or $a = c$.
    Since $(a, b, c)$ is reduced, either of the latter conditions would imply $b > 0$, so we have shown the conditions of the lemma to be necessary for $f$ to be reduced.
    It is easy to show that each condition is sufficient:
    \begin{align*}
        \textbf{(1)} \hspace{2mm}
        (a, 0, c) \cdot (a, 0, c) &= (a, 0, c) \cdot (a, -0, c) \\
        &= id_\Delta
    \end{align*}
    \begin{align*}
        \textbf{(2)} \hspace{2mm}
        (a, a, c) \cdot (a, a, c) &= (a, a, c) \cdot (a, -a, a - a + c) \rnote{\text{(using $T^{-1}$)}} \\
        &= (a, a, c) \cdot (a, -a, c) \\
        &= id_\Delta
    \end{align*}
    \begin{align*}
        \textbf{(3)} \hspace{2mm}
        (a, b, a) \cdot (a, b, a) &= (a, b, a) \cdot (a, -b, a) \rnote{\text{(using $S$)}} \\
        &= id_\Delta
    \end{align*}
    so these cases are necessary and sufficient to classify a form as ambiguous.
\end{proof}

Notice that each case reduces the three variables $a, b, c$ to only two --- 
consider how each case affects the formula $\Delta = b^2 - 4ac$
\begin{gather*}
    \textbf{(1)} \hspace{2mm} \Delta = 0 - 4ac = -4ac \\
    \textbf{(2)} \hspace{2mm} \Delta = a^2 - 4ac = a(a-4c) \\
    \textbf{(3)} \hspace{2mm} \Delta = b^2 - 4a^2 = (b + 2a)(b - 2a).
\end{gather*}
The theorem immediately follows:

\vspace{2mm}
\begin{theorem}
    An ambiguous form directly provides a (possibly trivial) factorisation of its discriminant.
\end{theorem}
\vspace{2mm}

\noindent
Therefore, if we want to find a factorisation of some number $N$, we can do this by finding ambiguous forms of discriminant $\Delta = -N$
(or $\Delta = -4N$ if $-N$ is congruent to 2 or 3 mod 4).

Suppose we devise a method to randomly sample reduced ambiguous forms of discriminant $\Delta$.
This is sufficient to constitute a factoring algorithm so long as a fixed percentage of such forms lead to nontrivial factorisations.
We will show that this is the case.

\vspace{2mm}
\begin{theorem} \label{thm-ambiguous-factorisations}
    If $N > 1$ is an odd composite integer which is not a perfect square, then at least one third of all reduced ambiguous forms of discriminant $\Delta$ lead to nontrivial factorisations of $N$, where
    $$\Delta = \begin{cases}
        -N & -N \equiv 1 \pmod{4} \\
        -4N & -N \equiv 3 \pmod{4}.
    \end{cases}$$
\end{theorem}

\begin{proof}
    Let us first consider the case that $-N \equiv 1 \pmod{4}$.
    We start by listing all reduced ambiguous forms of discriminant $-N$ which lead to the trivial factorisation $N = 1 \cdot N$.
    We can break this down by each kind of ambiguous form:

    \begin{adjustwidth}{12mm}{0pt}
        \noindent
        \llap{\textbf{(1)} \hspace{2mm}} \hspace{-3mm}
        We cannot have a form $(a, 0, c)$, since this gives $N = 4ac$, but $N$ is odd.

        \vspace{5mm}
        \noindent
        \llap{\textbf{(2)} \hspace{2mm}} \hspace{-3mm}
        A form $(a, a, c)$ gives $\Delta = a(a-4c)$, so we must choose $a$ to be $1$ or $N$.
        For a reduced form, $b$ (which here $=a$) must be less than $\sqrt{-\Delta / 3}$, so we must choose $a = 1$.
        Solving $-N = a - 4c$ for $c$, we get the ambiguous form
        $$\left( 1, 1, \frac{1 + N}{4} \right).$$
        This is reduced when $c \geq a$, which is met when $N \geq 3$, which is always the case given $N > 1$ is composite.

        \vspace{5mm}
        \noindent
        \llap{\textbf{(3)} \hspace{2mm}} \hspace{-3mm}
        A form $(a, b, a)$ gives $\Delta = (b + 2a)(b - 2a)$, so we can see that $b$ is the midpoint of the two factors, which are either $-1$ and $N$, or $1$ and $-N$.
        Since $b$ must be positive for such a form to be reduced, we must choose $b = \frac{N + 1}{2}$.
        Next, since $a$ is positive, we compute $a = \frac{N - 1}{4}$.
        This gives the ambiguous form
        $$\left( \frac{N - 1}{4}, \frac{N + 1}{2}, \frac{N - 1}{4} \right).$$
        This is reduced when $b \leq a$, i.e. $N \leq 3$, which is never the case.
    \end{adjustwidth}
    \vspace{2mm}
    We therefore see that there is only one reduced ambiguous form which gives a trivial factorisation.
    Now, since $N$ is composite, there exists some nontrivial factorisation $N = xy$, where $x \leq y$.
    Checking each kind of reduced form in a similar manner yields the forms
    $$\left(x, x, \frac{x + y}{4}\right) \text{ and } \left( \frac{x + y}{4}, \frac{y - x}{2}, \frac{x + y}{4} \right).$$
    Note that $\Delta = -xy \equiv 1 \pmod{4}$, which means $-x$ and $y$ are both either 1 or 3 mod 4, so $x + y$ is divisible by 4, and $x - y$ is even ---
    so the entries in the above forms are integers.
    These forms are reduced when $3x \leq y$ and $3x \geq y$, respectively.
    So there is always at least one reduced form which gives the factorisation $N = xy$.
    Since there is only one reduced form which gives a trivial factorisation, at least half of all reduced ambiguous forms give nontrivial factorisations.
    
    We repeat this argument for the case $-N \equiv 3 \pmod{4}$.
    We set $\Delta = -4N$, and consider the forms which lead to trivial factorisations of $4N$, which are $1 \cdot 4N$, $2 \cdot 2N$, and $4 \cdot N$.
    \begin{adjustwidth}{12mm}{0pt}
        \vspace{5mm}
        \noindent
        \llap{\textbf{(1)} \hspace{2mm}} \hspace{-3mm}
        The only reduced form $(a, 0, c)$ corresponding to a trivial factorisation is $(1, 0, N)$.

        \vspace{5mm}
        \noindent
        \llap{\textbf{(2)} \hspace{2mm}} \hspace{-3mm}
        A form $(a, a, c)$ is trivial if $a$ is chosen to be 1, 2, or 4 ($N$, $2N$, and $4N$ cannot be chosen or else the form would not be reduced).
        Solving for $c$ only gives an integer when $a = 2$, in which case we get the ambiguous form
        $$\left(2, 2, \frac{1 + N}{2} \right).$$

        \vspace{5mm}
        \noindent
        \llap{\textbf{(3)} \hspace{2mm}} \hspace{-3mm}
        A form $(a, b, a)$ gives $\Delta = (b + 2a)(b - 2a)$, so $b$ is the midpoint of the two factors.
        For $b$ to be an integer, the factors must be congruent mod 2, so we either have $-2 \cdot 2N$ or $2 \cdot -2N$.
        For such a form to be reduced, $b$ must be positive, so we are in the prior case, where $b = N - 1$.
        This gives 
        $$b - 2a = -2 \implies a = \frac{N + 1}{2}.$$
        So we have the ambiguous form
        $$\left( \frac{N + 1}{2}, N - 1, \frac{N + 1}{2} \right).$$
        This is reduced when $b \leq a$, which is satisfied when $N \leq 2$, which is never the case.
    \end{adjustwidth}
    \vspace{2mm}
    So there are precisely two reduced ambiguous forms which lead to trivial factorisations.
    Again, let $N = xy$ be a nontrivial factorisation, this time asserting that $x \neq y$ (which is possible, since $N$ is not a perfect square).
    Choose these such that $x < y$. 
    We immediately obtain the form $(x, 0, y)$ which gives a nontrivial factorisation.
    By further examining the 2nd and 3rd kinds of ambiguous forms, we get
    $$\left( 2x, 2x, \frac{x + y}{2} \right) \text{ and } \left( \frac{x + y}{2}, y - x, \frac{x + y}{2} \right).$$
    Since $N$ is odd, both $x$ and $y$ are odd, so $x + y$ is divisible by 2, meaning that these forms have integer coefficients.
    These forms are reduced when $3x \leq y$ and $3x \geq y$, respectively, so there are always at least two reduced ambiguous forms which give the factorisation $N = xy$.
    Since we asserted $x \neq y$, neither form can be $(x, 0, y)$.
    Since only two reduced forms give trivial factorisations, at least half of all reduced ambiguous forms give nontrivial factorisations.
\end{proof}

Note, though, what happens if $N$ has a square component (other than 4).
Let $\Delta = -s^2 r$, where $s$ and $r$ are positive and $s > 2$.
Suppose we want to find an ambiguous form which gives us the factorisation $\Delta = s \cdot -sr$.
Such a form is one of the following:
$$\left( s, 0, \frac{-sr}{4} \right), \left(s, s, \frac{s - sr}{4}\right), \left(\frac{s - sr}{4}, \frac{sr - s}{2}, \frac{s - sr}{4}\right).$$
In each case, the resulting form is non-primitive, since $s$ divides each term.
One can see that an ambiguous form corresponding to $N = xy$ is non-primitive precisely when $x$ and $y$ have a common factor (this will be important later).

In order to factor $N$, we desire to find a method for sampling reduced ambiguous forms.
Suppose we can generate a random reduced ambiguous form using some algorithm. 
There is at least 50\% chance that the form we generate gives a nontrivial factorisation, otherwise we sample again.
Let the expected number of samples needed be $E$.
At least half of the time, the first sample gives a nontrivial factorisation, the other half we will require $1 + E$ steps, so
$$E \leq \frac{1}{2}(E) + \frac{1}{2}(1 + E) \implies E \leq 2.$$
So if we take repeated samples until we get a nontrivial factorisation of the discriminant from one of the ambiguous forms, the expected running time of this algorithm is a constant factor $\leq 2$ times the running time of the sampling algorithm.
This means that the possibility of having to take multiple samples doesn't increase the growth class of our factoring algorithm.

\section{Baby Step Giant Step} \label{s-bsgs}
Since $\Cl_\Delta$ is a finite group, each element has some finite order.
That is, for a form $f$, there exists some $d \in \N$ such that
$$f^d \sim id_\Delta.$$
If $d$ happens to be even, then we have
$$(f^{d/2})^2 \sim id_\Delta.$$
Hence, $f^{d/2}$ must be an ambiguous form, which gives a (possibly trivial) factorisation of the discriminant.
We will postpone discussing how uniformly this process samples the set of ambiguous forms until \Cref{s-sampling-forms}.
For now, suppose that we can choose a random reduced form, we hope that there is a reasonable probability that its order is even.
Fortunately, this is the case ---
in fact, we claim the following:

\vspace{2mm}
\begin{theorem}
    If $N > 1$ is an odd composite integer, then at least half of all elements of $\Cl_\Delta$ have even order, where $\Delta$ is $-N$ or $-4N$ as before.
\end{theorem}

\begin{proof}
    We first claim that $\Cl_\Delta$ contains at least one ambiguous form which is not the identity.
    We already saw in the proof of \Cref{thm-ambiguous-factorisations} that $\Cl_\Delta$ contains a reduced ambiguous form which is not the identity, which has order 2.
    Since the order of each element divides the order of the group, $\Cl_\Delta$ has even order.
    By the structure theorem for finite abelian groups, $\Cl_\Delta$ can be written as the product of two groups, one of which has order equal to a power of 2.
    All elements with a nonzero component in this group have even order, which is at least half of all elements.
\end{proof}

So if we can sample a random reduced form $f$, the order of $f$ will be even at least half of the time, allowing us to find an ambiguous form.
To efficiently find the order of an element, we use a method discovered by Daniel Shanks called \textbf{Baby Step Giant Step}, (or BSGS).

BSGS uses a ``meet in the middle'' strategy, which requires we have some bound on the size of the class group.
We call the order of the class group the \textbf{class number}, $h_\Delta = |\Cl_\Delta|$.
Suppose we have an upper bound $H \geq h_\Delta$ (we will find such a bound in \Cref{s-class-number-formula}).
We first compute the first $\lceil \sqrt{H} \rceil$ powers of $f$ (``baby steps'').
If this process produces the identity, we are done. 
Otherwise, we compute the first $\lceil \sqrt{H} \rceil$ powers of $f^{\lceil \sqrt{H} \rceil}$ (``giant steps'').
All powers of $f$ from $\lceil \sqrt{H} \rceil + 1$ up to $H$ are given by multiplying a baby step with a giant step, and the order of $f$ cannot be larger than $H$, so one of these products must be the identity.
This means that one of the giant steps is an inverse to one of the baby steps.
If we store our baby steps in a hash table, then as we calculate the giant steps, we can check if their inverses are in the hash table.
Once a collision is found between the $i$-th baby step and the $j$-th giant step, we have found
$$\text{id}_\Delta = f^i \cdot (f^{\lceil \sqrt{H} \rceil})^j = f^{i + \lceil \sqrt{H} \rceil j}.$$
Since we check all powers of $f$ in increasing order, this is the first positive power of $f$ which gives the identity, so the order of $f$ is $i + \lceil \sqrt{H} \rceil j$.
As an algorithm, we have
\begin{algorithm}
    \caption{Baby Step Giant Step} \label{alg-bsgs}
    \DontPrintSemicolon
    \vspace{1mm}
    \KwIn{$f \in \Cl_\Delta, H \in \Z$ such that $H \geq h_\Delta$.}
    \KwOut{$d \in \Z$ where $d$ is the order of $f$.}
    \algosep

    \If{$f = \text{id}_\Delta$}{
        \Return{1}
    }
    Initialise a hash table $B$.\;
    $b \gets f$\;
    To $B$, add the key $b$ with the value $1$.\;

    \For{$i \gets 2$ \KwTo $\lceil \sqrt{H} \rceil$} {
        $b \gets b \cdot f$\;
        \If{$b = \text{id}_\Delta$}{
            \Return{$i$}
        }
        To $B$, add the key $b$ with the value $i$.\;
    }

    $g \gets \text{id}_\Delta$\;
    \For{$j \gets 1$ \KwTo $\lceil \sqrt{H} \rceil$} {
        $g \gets g \cdot b^{-1}$\;
        \If{$g$ is a key in $B$}{
            $i \gets$ value at key $g$ in $B$.\;
            \Return{$i + j \lceil \sqrt{H} \rceil$}
        }
    }
\end{algorithm}

\noindent
This algorithm computes the order of an element in $O(\sqrt{H})$ composition and hash table operations.

Once we have computed the order of $f$, we can efficiently raise $f$ to a power using a binary powering algorithm:
we consider the binary expansion of $d$, i.e.
$$d = a_0 \cdot 2^0 + a_1 \cdot 2^1 + a_2 \cdot 2^2 + \dots \rnote{(a_i \in \{0, 1\}).}$$
Then we have
$$f^d = (f)^{a_0} \cdot (f^2)^{a_1} \cdot (f^4)^{a_2} \cdot (f^8)^{a_3} \cdot \dots$$
So instead of multiplying $f$ by itself $d$ times, we take repeated squares $\lceil \log_2(d) \rceil$ times, and multiply all terms corresponding to 1s in the binary expansion of $d$.

\pagebreak
\begin{algorithm}
    \caption{Binary Powering Algorithm} \label{alg-fast-power}
    \DontPrintSemicolon
    \vspace{1mm}
    \KwIn{$f$ in some group, $d \in \N$ where $d \neq 0$.}
    \KwOut{$f^d$.}
    \algosep
    $g \gets f$\;
    $h \gets \text{id}$\;
    \For{$i \gets 0$ \KwTo $\lceil \log_2{d} \rceil$} {
        \If{$\lfloor d / 2^{i} \rfloor \equiv 1 \pmod{2}$}{
            $h \gets h \cdot g$\;
        }
        $g \gets g^2$\;
    }
    \Return{$h$}
    \vspace{2mm}
\end{algorithm}

\noindent
This allows us to compute $f^{d/2}$ in $O(\log_2(H))$ composition operations and hash table operations.

We will see that the slowest step in the method of factoring that we are developing is computing the order of an arbitrary element.
This depends on the bound $H$, so the smaller we can make this bound, the faster our factoring method will be.
Suppose we simply use a counting argument to bound the number of reduced forms.
For reduced positive definite forms, we have shown $|b| \leq \sqrt{|\Delta|/3}$.
Note that $b \equiv \Delta \pmod{2}$, so only half of the values of $b$ in this range are valid candidate choices.
Once we fix $b$, the choices for $a$ and $c$ are given by factor pairs of 
$$\frac{b^2 - \Delta}{4} \leq \frac{\frac{| \Delta |}{3} + | \Delta |}{4} = \frac{|\Delta|}{3}.$$
The number of ways to split this term into two factors is bounded above by
$$2 \cdot \sqrt{\frac{|\Delta|}{3}}.$$
So the total number of reduced forms is bounded by
$$h_\Delta \leq \sqrt{\frac{|\Delta|}{3}} \cdot 2 \cdot \sqrt{\frac{|\Delta|}{3}} = \frac{2 |\Delta|}{3}.$$
This bound allows us to compute the order of a form of discriminant $\Delta$ with time complexity $O(\sqrt{|\Delta|})$.
This bound gives an algorithm which is in a growth class no faster than trial division.
As such, we will need a better bound.

\section{Bounding the Class Number} \label{s-class-number-formula}

In the factoring method outlined by Shanks, one attempts to compute the precise class number using the analytic class number formula:
\vspace{2mm}
\begin{theorem}
    For $\Delta < -4$, the class number is given by
    $$h_\Delta = \frac{\sqrt{|\Delta|}}{\pi} L(1, \chi_\Delta) \hspace{5mm}$$
    where $L(s, \chi) = \sum_{n = 1}^{\infty} \frac{\chi(n)}{n^s}$, and $\chi_\Delta(n) = (\Delta / n)$ is the Kronecker symbol.
\end{theorem}
\vspace{2mm}
For a proof of this theorem, see \cite[\S\,10.5]{jarvis}.
Shanks approximates this using a product over primes $p$ \cite[\S\,2]{shanks}:
$$h_\Delta \approx \frac{\sqrt{|\Delta|}}{\pi} \prod_{p=2}^{P} \frac{p}{p - (\Delta / p)}$$
where $P$ is suitably large.
He then takes further steps to verify that his approximation is likely to be correct.
We will take a different approach, simply finding an upper bound for the $L$-series.
\vspace{2mm}
\begin{theorem} \label{thm-h-bound}
    For $\Delta < -4$, the class number is bounded above by
    $$h_\Delta < \frac{\sqrt{|\Delta|}}{\pi}(\ln|\Delta| + 2).$$
\end{theorem}

\begin{proof}
    \emph{This proof is based on a proof generated by ChatGPT.}
    We will construct a bound on $L(1, \chi_\Delta)$ using the fact that $\chi_\Delta$ is a Dirichlet character mod $|\Delta|$.
    First, we split the sum
    $$L(1, \chi_\Delta) = \sum_{n = 1}^{\infty} \frac{\chi_\Delta(n)}{n} = \sum_{n = 1}^{|\Delta|} \frac{\chi_\Delta(n)}{n} + \sum_{n = |\Delta| + 1}^{\infty} \frac{\chi_\Delta(n)}{n}.$$
    To bound the first sum, we observe that $|\chi_\Delta| \leq 1$, so
    $$\left| \sum_{n = 1}^{|\Delta|} \frac{\chi_\Delta(n)}{n} \right| \leq 1 + \sum_{n = 2}^{|\Delta|} \frac{1}{n} \leq 1 + \int_{1}^{|\Delta|} \frac{dx}{x} = 1 + \ln|\Delta|.$$
    To bound the second sum, we will use Abel summation.
    First, define
    $$A(N) = \sum_{n = 1}^{N} \chi_\Delta(n).$$
    Since $\chi_\Delta$ is a Dirichlet character mod $|\Delta|$, it has the property
    $$\sum_{n = k}^{k + |\Delta| - 1} \chi_\Delta(n) = 0 \rnote{\forall k \in \Z.}$$
    So $A(k|\Delta|) = 0$ for all integers $k$, and to bound $A(n)$ in general, note that the sum of the first $k|\Delta|$ terms of the sum cancel, leaving at most $|\Delta| - 1$ terms in the sum, giving
    $$|A(n)| \leq |\Delta| - 1 \leq |\Delta|.$$
    Now, we can write $\chi_\Delta(n) = A(n) - A(n - 1)$, which gives
    \begin{align*}
        \sum_{n = |\Delta| + 1}^{N} \frac{\chi_\Delta(n)}{n} &= \sum_{n = |\Delta| + 1}^{N} \frac{A(n) - A(n - 1)}{n} \\
        &= \sum_{n = |\Delta| + 1}^{N} \frac{A(n)}{n} - \sum_{n = |\Delta|}^{N - 1} \frac{A(n)}{n + 1} \\
        &= \frac{A(N)}{N} + \sum_{n = |\Delta| + 1}^{N - 1} \left( \frac{A(n)}{n} - \frac{A(n)}{n + 1} \right) - \frac{A(|\Delta|)}{|\Delta| + 1} \\
        &= \frac{A(N)}{N} + \sum_{n = |\Delta| + 1}^{N - 1} A(n) \left( \frac{1}{n} - \frac{1}{n + 1} \right) \\
        \llap{$\implies$} \left| \sum_{n = |\Delta| + 1}^{N} \frac{\chi_\Delta(n)}{n} \right| &\leq \frac{|\Delta|}{N} + |\Delta| \sum_{n = |\Delta| + 1}^{N - 1} \left( \frac{1}{n} - \frac{1}{n + 1} \right) \\
        &= \frac{|\Delta|}{N} + |\Delta| \left( \frac{1}{1 + |\Delta|} - \frac{1}{N} \right)
    \end{align*}
    Taking the limit as $N \rightarrow \infty$, we have
    $$\left| \sum_{n = |\Delta| + 1}^{\infty} \frac{\chi_\Delta(n)}{n} \right| \leq 0 + \frac{|\Delta|}{1 + |\Delta|} - 0 < 1.$$
    Combining these bounds, we get
    $$L(1, \chi_{\Delta}) < \ln|\Delta| + 2.$$
    Substituting this into the analytic class number formula gives the desired bound.
\end{proof}

\section{Sampling Forms} \label{s-sampling-forms}

The last component missing from our factoring algorithm is a method for randomly sampling reduced forms.
This isn't as easy as it might first seem --- 
for instance, if one chooses some $b$ congruent to $\Delta$ mod 2, then it remains to find $a$ and $c$ satisfying $ac = \frac{b^2 - \Delta}{4}$.
That is, we have to factor a number which is similar in size to $\Delta$.

Shanks offers a better method.
He suggests taking ``small'' primes $p$ such that $\Delta$ is a quadratic residue mod $p$ \cite[\S\,2]{shanks}.
Then one can find $b$ such that $b^2 \equiv \Delta \pmod{p}$, which gives the form
$$\left( p, b, \frac{b^2 - \Delta}{4p} \right).$$
Note that $\Delta - b^2 \equiv 0 \pmod{4}$, so the entries of the above form are integers (except perhaps when $p = 2$).
This method is particularly convenient for Shanks, since he has already calculated $(\Delta / p)$ for many small primes, which is 1 precisely when $\Delta$ is a quadratic residue mod $p$.

But should we expect such a method to sample forms from all reduced forms with equal likelihood?
In fact, we will show this does sample the set of reduced primitive forms uniformly, since this method of sampling is equivalent to uniformly sampling from the set of prime ideals of $\order_\Delta$ and then mapping these to the corresponding forms.
To see this, we must understand what the prime ideals of $\order_\Delta$ look like.

\vspace{2mm}
\begin{lemma}
    Every prime ideal $\mathfrak{p} \trianglelefteq \order_\Delta$ sits above an integer prime ideal $p\Z \trianglelefteq \Z$.
    That is, there is some prime $p \in \Z$ such that
    $$\mathfrak{p} \cap \Z = p\Z.$$
\end{lemma}

\begin{proof}
    Suppose $\mathfrak{p} \cap \Z = pq\Z$, where $p$ and $q$ are integers greater than 1.
    Then $pq \in \mathfrak{p}$, but neither $p$ nor $q$ is in $\mathfrak{p}$.
    This contradicts the definition of a prime ideal.
    So we must have $\mathfrak{p} \cap \Z = p\Z$ for a prime integer $p$.
\end{proof}

\noindent
Over $\order_\Delta$, an odd prime $p \in \Z$ is
\begin{itemize}
    \item \textbf{Inert} if $\Delta$ is not a quadratic residue mod $p$.
    \item \textbf{Split} if $\Delta$ is a quadratic residue mod $p$ and $p \nmid \Delta$.
    \item \textbf{Ramified} if $p \divides \Delta$.
\end{itemize}

\vspace{2mm}
\noindent
We will say that a prime ideal is inert/split/ramified if it sits above an integer prime ideal $p\Z$, where $p$ is inert/split/ramified over $\order_\Delta$.
We now attempt to understand the distribution of invertible prime ideals.
Note that if a prime ideal $\mathfrak{p}$ sits over $p\Z$, then in the canonical representation
$$\mathfrak{p} = l\Z + \frac{m + n\sqrt\Delta}{2}\Z$$
so we must have $l = p$.
We must check if there is a suitable choice for $m$ such that $\mathfrak{p}$ is an ideal.
Checking the conditions of \Cref{lemma-lattice-divisibility-conditions}, we know that $n \divides p$, so $n$ is either $p$ or 1.
$n = p$ corresponds to the principal ideal $\langle p \rangle$ (which isn't necessarily prime), let us consider the case when $n = 1$.
Conditions 1 and 3 of \Cref{lemma-lattice-divisibility-conditions} follow immediately from $n = 1$.
The other conditions require
\begin{gather*}
    \lnote{\textbf{2.}} m \equiv \Delta \pmod{2} \\
    \lnote{\textbf{4.}} 4p \divides m^2 - \Delta
\end{gather*}
If condition 2 is satisfied, then $m^2 - \Delta \equiv 0 \pmod{4}$, which reduces condition 4 to
$$\Delta \equiv m^2 \pmod{p}$$
i.e. $\Delta$ is a quadratic residue mod $p$.
Suppose this is the case, and $b^2 \equiv \Delta \pmod{p}$.
Then $b^2$ is one of 0 or 1 mod 4, while $(b+p)^2$ is the opposite.
One of these is a suitable choice for $m$ such that condition 2 is satisfied.
So we can find an ideal $\mathfrak{p}$ if and only if $\Delta$ is a quadratic residue mod $p$, so inert primes can only have $\langle p \rangle$ as possible prime ideals sitting above them.
If $m = 0$, (i.e. $p \divides \Delta$, $p$ is ramified) then there is only one choice for $\mathfrak{p}$.
If $m \neq 0$, $p$ is split, and $-m$ is also a valid choice which meets the divisibility conditions and defines a different ideal $\mathfrak{p}$.

\vspace{2mm}
\begin{theorem}
    Let $p \in \Z$ be an odd prime and $b$ be a nonzero integer such that $b^2 \equiv \Delta \pmod 4p$.
    Then
    $$\mathfrak{p} = p\Z + \frac{b + \sqrt\Delta}{2}\Z$$
    is a prime ideal of $\order_\Delta$.
\end{theorem}

\begin{proof}
    We will show that $\mathfrak{p}$ is maximal and therefore prime.
    Consider some 
    $$z = x + y\frac{\Delta + \sqrt\Delta}{2} \in \order_\Delta \backslash \mathfrak{p}.$$
    Then consider the ideal generated by $\mathfrak{p}$ and $z$, that is $I = \langle p, \frac{b + \sqrt\Delta}{2}, z \rangle$.
    Note that
    $$y\frac{b + \sqrt\Delta}{2} \in \mathfrak{p} \implies z - y\frac{b + \sqrt\Delta}{2} = x + y\frac{\Delta - b}{2} \notin \mathfrak{p}$$
    but this element is in $I$.
    This element is an integer, and it must not be divisible by $p$, since it is not in $\mathfrak{p}$.
    But that means that $I$ contains $p$ as well as an integer which is coprime to $p$, so it contains 1, and therefore is all of $\order_\Delta$.
    Therefore, we cannot add another element to $\mathfrak{p}$ without getting all of $\order_\Delta$, so $\mathfrak{p}$ is maximal and therefore prime.
\end{proof}

For our factoring algorithm, we will sample primes $p$ on the interval $[3, |\Delta|]$.
Whenever $\Delta$ is not a quadratic residue mod $p$, we sample again. 
About half of the samples $p$ will satisfy this condition if we sample primes on a large enough range \cite[Exercise\,11.3.5]{}.
Whenever $p \divides \Delta$, we have immediately found a nontrivial factor of $\Delta$ and can cease the algorithm.
Otherwise, when $\Delta$ is a quadratic residue mod $p$, we can compute $b$ such that $b^2 \equiv \Delta \pmod{p}$, which corresponds to sampling a split prime ideal.
Note that we have two choices for $b$, but one choice gives the inverse class to the other ---
the two resulting forms will land on the same ambiguous form in our factoring method, so it doesn't matter if we differentiate between choices of $b$.

It is now natural to ask, how are split prime ideals distributed among the class group?
To answer this, we have a useful density theorem:

\vspace{2mm}
\begin{theorem}
    Invertible prime ideals of $\order_\Delta$ are equally distributed among narrow equivalence classes of invertible ideals.
    That is, for an invertible class $C$,
    $$\lim_{N \rightarrow \infty} \frac{|\{ \text{prime } \mathfrak{p} \in C : N(\mathfrak{p}) \leq N \}|}{|\{ \text{invertible prime } \mathfrak{p} \trianglelefteq \order_\Delta : N(\mathfrak{p}) \leq N \}|} = \frac{1}{h_\Delta}.$$
\end{theorem}
\vspace{2mm}

\noindent
This theorem comes from using class field theory to realise the class group as a Galois group \cite[Equation 9.1]{cox}, at which point the Chebotarev density theorem can be applied \cite[Equation 1.1]{lagarias}.
The details of such a proof are beyond the scope of this paper ---
for verification of this theorem, see the references above.

This theorem states that invertible prime ideals are uniformly distributed among classes of invertible ideals.
There are only finitely many ramified invertible prime ideals, since only finitely many primes divide the discriminant, and all inert prime ideals belong to the principal class.
Therefore, split invertible prime ideals are equally distributed amongst classes (except perhaps for the principal class, which may be underrepresented, which is not a problem for our factoring algorithm).
So by sampling primes until one is split over $\order_\Delta$, we are sampling from the ideal class group effectively uniformly ---
the corresponding form is precisely the form $(p, b, c)$ described earlier, which once reduced is effectively a uniform sample from the set of reduced primitive forms of discriminant $\Delta$.

Note that the Chebotarev density theorem considers the density of all invertible prime ideals, while we only sample prime ideals of norm no greater than $|\Delta|$.
We will not prove formally that this is sufficient --- 
such a proof would involve a finite-bounded version of the density theorem.
We will, however, observe computational evidence that this bound is likely sufficient for our purposes in \Cref{s-factoring-algorithm}.

Also note that we are only able to sample primitive forms in this way. 
If the number we are trying to factor is $N = s^2r$ where $r$ is square-free, we are only able to find factors in $r$ using this method.
There is a simple solution to this problem - we simply check if the number that we are trying to factor is a perfect square.
If so, it is easy to find a factor (via the square root).
Otherwise, we are still able to find factors dividing $r$ using the method that we have developed.

\section{The 2-Sylow Subgroup}
Now we are able to (roughly) uniformly sample reduced primitive forms.
We previously suggested that we can sample a random reduced form $f$, compute its order $d$, and if $d$ is even we compute $f^{d/2}$, an ambiguous form.
There remains a question of how uniformly this process samples the set of reduced ambiguous forms.
In fact, this concern is well-founded, as there are cases where this method samples non-uniformly.
Worse yet, there are cases where this process is strongly biased towards sampling an ambiguous form which corresponds to a trivial factorisation.
To understand why this issue occurs and how to avoid it, we must discuss the \textbf{2-Sylow subgroup} of $\Cl_\Delta$.
This is given by
$$S_\Delta = \{ \bar{f} \in \Cl_\Delta : \text{ord}({\bar{f}}) = 2^k, \hspace{2mm} k \in \Z \}.$$
One can easily verify that this is a subgroup, and it is clearly the largest subgroup with order $2^k$, since the order of a group is divided by the order of each element, so no more elements of $\Cl_\Delta$ can be added to this group without making its order no longer a power of 2.
Now, we can adapt our method for finding ambiguous forms to a method for sampling $S_\Delta$:
\begin{algorithm}
    \caption{Sampling the 2-Sylow Subgroup} \label{alg-sylow-sample}
    \DontPrintSemicolon
    \vspace{1mm}
    \KwIn{$\Delta \in \Z$ a negative discriminant.}
    \KwOut{$s$, a form of discriminant $\Delta$ with order equal to a power of 2.}
    \algosep
    $f \gets$ random form of discriminant $\Delta$ (using the method in \Cref{s-sampling-forms}).\;
    $B \gets$ order of $f$ (using \Cref{alg-bsgs} with the bound from \Cref{s-class-number-formula}).\;
    \While{$2 \divides B$}{
        $B \gets B / 2$\;
    }
    $s \gets f^B$ (using \Cref{alg-fast-power}).\;
    \Return{$s$}
    \vspace{2mm}
\end{algorithm}

\begin{lemma}
    \Cref{alg-sylow-sample} samples $S_\Delta$ uniformly.
\end{lemma}

\begin{proof}
    It is immediately clear that the output $s \in S_\Delta$, since 
    $$s^{2^A} = f^{B \cdot 2^A} = f^{\text{ord}(f)} = \text{id}_\Delta.$$
    By the structure theorem for finite abelian groups, $\Cl_\Delta \simeq S_\Delta \times G$ for some group $G \subseteq Cl_\Delta$.
    So for a form $f$, we can uniquely write $f = s'g$, where $s' \in S_\Delta, g \in G$.

    Now consider that the action $f \mapsto f^B$ is a permutation of $S_\Delta$ whenever $2 \nmid B$.
    It is injective, since 
    $$f^B = g^B \implies (fg^{-1})^B = \text{id}_\Delta$$
    which implies the order of $fg^{-1}$ divides $B$, and can therefore only be 1 (i.e. $f = g$).
    The map is also surjective, by finiteness of $S_\Delta$.

    Now, sampling $f = s'g$ is equivalent to sampling some $g \in G$, and then sampling $s' \in S_\Delta$.
    Letting the order of this element be $2^A \cdot B$ where $2 \nmid B$, note that the value of $A$ is completely determined by $s'$, and the value of $B$ is completely determined by $g$.
    Therefore, if we first sample $g \in G$, then we can immediately determine $B$.
    Before even choosing $s'$, note that
    $f^B = s'^B g^B = s'^B.$
    Our choice of $s'$ will simply be permuted when taken to the power of $B$.
    Hence, the result is a uniformly distributed sample from $S_\Delta$.
\end{proof}

Now, consider sampling $s \in S_\Delta$, computing its order $d$, and then getting the ambiguous form $s^{d/2}$, we have claimed that this method does not uniformly sample the set of reduced ambiguous forms.
To see this, consider the case that $S_\Delta \simeq \Z_2 \times \Z_{64}$.
Denoting the elements of this group as $(a, b)$, with $a \in \Z_2, b \in \Z_{64}$, the square of every element is of the form $(0, b)$.
This means the ambiguous forms $(1, 0)$ and $(1, 32)$ cannot be found by any $s^{d/2}$ except for when $s$ is itself ambiguous.
Shanks claims that $\Delta = -4 \cdot 10721$ leads to this exact case, where out of 128 elements of the 2-Sylow subgroup, 125 of them lead to the same ambiguous form, $(2, 2, 5361)$, which corresponds to a trivial factorisation of the discriminant \cite[\S\,7]{shanks}.

Shanks calls ambiguous forms which are overrepresented by our sampling algorithm \textbf{parasitic forms}.
Fortunately, he also provides a method to mitigate their effect on the running time of our factoring algorithm.
He suggests that if the same parasitic form is encountered many times, then it will arise as the square of distinct forms of order 4 (since we are commonly getting this form as $s^{2^{A-1}}$, so $s^{2^{A-2}}$ is a square root).
Suppose two such distinct ``square roots'' of the parasitic form $P$ are $f$ and $g$ which are not inverses of each other, then consider the form $fg^{-1}$.
This is ambiguous, since
$$(fg^{-1})^2 = f^2 (g^2)^{-1} = PP^{-1}  = \text{id}_\Delta.$$
We know that $fg^{-1}$ is not the identity, since $f \neq g$.
We also know that it is not $P$, since $f \neq g^{-1}$.
So it seems that we have a way of generating ambiguous forms which are not the parasitic form.
But there is still a problem ---
what if we keep finding the same form which squares to $P$?
Fortunately, the argument generalises, although it is still only a heuristic result.

When we sample a form $f$ and compute its order to be $2^A \cdot B$, then $h = f^B$ is a random uniform sample from $S_\Delta$.
We will repeatedly square this element, and as we do, we will store each encountered element in a hash table, along with the element which squares to $s$.
This way, when we take a new sample, if we ever encounter an element $s \in S_\Delta$ which we have seen before, we now have two distinct forms which square to that element (unless the first element, $h$, has been encountered before, which is unlikely since it was sampled uniformly).
Calling these forms $g$ and $g'$, we now consider the form given by $g^{-1}g'$.
This is ambiguous, since
$$(g^{-1}g')^2 = (g^2)^{-1}g'\hspace{0.5mm}^2 = s^{-1}s = \text{id}_\Delta.$$
If $g$ is fixed, there is only one choice for $g'$ which gives the same ambiguous form as if we simply increased the power of $s$ as usual.
If $s$ is parasitic, then either it has lots of forms which square to $s$, or there is another parasitic form of higher order which squares to $s$.
In the former case, there are lots of choices for $g'$, so $g^{-1}g'$ is likely to be a new ambiguous form.
In the latter case, if we reached $s$ through its parasitic ``square root,'' then the argument is made for that square root instead (i.e. we likely hit that form by squaring different elements).
The effectiveness of this method is tested computationally in \Cref{s-factoring-algorithm}.

\section{The Factoring Algorithm} \label{s-factoring-algorithm}

The methods we have discussed in this chapter are sufficient to arrive at a factoring algorithm.

\begin{center}
\makebox[\textwidth][r]{
\clipbox{0pt 7.4cm 0pt 0pt}{
\begin{minipage}{\textwidth}
    
\begin{algorithm}[H]
    \caption{Factoring via Ambiguous Forms} \label{alg-factor}
    \DontPrintSemicolon
    \vspace{1mm}
    \KwIn{$N \in \N$, a composite integer.}
    \KwOut{$x \in \N$, a nontrivial factor of $N$.}
    \algosep

    \vspace{2mm}
    \If{$2 \divides N$}{
        \Return{2}
    }

    \vspace{2mm}
    \If{$|N|$ is a perfect square} {
        \Return{$\sqrt{|N|}$}
    }

    \vspace{2mm}
    $\Delta \gets \begin{cases} -|N| & -|N| \equiv 1 \pmod{4} \\ -4|N| & -|N| \equiv 3 \pmod{4} \end{cases}$\;

    \vspace{2mm}
    Initialise a hash map $S$ which uses forms in the 2-Sylow subgroup as keys, storing a form which squares to the key.\;

    \vspace{2mm}
    \While{no nontrivial factor has been found}{

        \vspace{2mm}
        $p \gets$ random prime in $[3, |\Delta|]$, which can be chosen by sampling integers until one is found to be prime via a primality test such as the Miller-Rabin test \cite[Alg.\,8.2.2]{cohen}.\;

        \vspace{2mm}
        \If{$p \divides \Delta$}{
            \Return{$p$}
        }

        \vspace{2mm}
        \If{$\Delta$ is a quadratic nonresidue mod $p$}{
            Return to the start of the loop.
        }

        \vspace{2mm}
        $b \gets$ a square root of $\Delta$ mod $p$, which can be computed using an algorithm such as the Tonelli-Shanks algorithm \cite[Alg.\,1.5.1]{cohen}.
        If $4 \nmid (b^2 - \Delta)$, then $b \gets b + p$.\;

        \vspace{2mm}
        $\displaystyle f \gets \left( p, b, \frac{b^2 - \Delta}{4p} \right)$\;

        \vspace{2mm}
        $d \gets$ order of $f$, computed using BSGS algorithm with the upper bound $H = \frac{\sqrt{|\Delta|}}{\pi} (\ln|\Delta| + 2$).\;

        \vspace{2mm}
        \If{$d$ is odd}{
            Return to the start of the loop.
        }

        \vspace{2mm}
        $g \gets f^{d/2}$ using the binary powering algorithm.\;

        \vspace{2mm}
        $x \gets$ factor extracted from $g$. 
        If $g$ has the form $(a, b, a)$, this is $2a - b$.
        Otherwise, $g$ has the form $(a, 0, c)$ or $(a, a, c)$ --- 
        in both cases the factor is $a$.\;

        \vspace{2mm}
        \If{$x$ is nontrivial}{
            \Return{$x/4$ if $4 \divides x$, $x/2$ if $2 \divides x$, or otherwise $x$.}
        }

        \vspace{2mm}  
        Compute $d = 2^A \cdot B$ where $2 \nmid B$.\;

        \vspace{2mm}
        $h \gets f^{B}$\;

        \vspace{2mm}
        \While {$h \neq \text{id}_\Delta$}{
            $h2 \gets h^2$\;

            \vspace{2mm}
            \If{$h2$ is a key in $S$}{
                $g \gets h^{-1} \cdot$ value at key $h2$ in $S$.\;
                $x \gets$ factor extracted from $g$, as before.

                \vspace{2mm}
                \If{$x$ is nontrivial}{
                    \Return{$x/4$ if $4 \divides x$, $x/2$ if $2 \divides x$, or otherwise $x$.}
                }
            }
            \Else{
                To $S$, add the key $h2$ with the value $h$.\;
            }
            $h \gets h2$\;
        }
    }
\end{algorithm}

\end{minipage}}}
\end{center}

\vspace{2mm}
\noindent
A Python implementation of this algorithm can be found at \url{https://github.com/HarrisonGraham14/Factoring}.
Note that the suggested Miller-Rabin test is probabilistic, and can return false positives for the primality of $p$. 
But even if this occurs, no real harm is done.
We can add a step to check that $f$ is a primitive form by computing the gcd of its coefficients.
If this is not 1, compositions using $f$ are not defined, and we cannot proceed ---
however, the gcd of the coefficients of $f$ divides the discriminant of $f$, so in this case we have found a factor of $D$ which may be nontrivial.

Let us briefly consider the time complexity of this algorithm:
\begin{itemize}
    \item The Miller-Rabin primality test is $O(\ln^3|\Delta|)$ \cite[\S\,8.2]{cohen}.
    By the prime number theorem, there is about a $1/\ln|\Delta|$ chance that each sample is prime, so we will need an average of $\ln|\Delta|$ samples before one is found to be prime.
    Hence, this part of the algorithm has running time $O(\ln^4|\Delta|)$

    \item The Tonelli-Shanks algorithm has expected time complexity of $O(\ln^4|\Delta|)$ \cite[\S\,1.5.1]{cohen}.
    Reducing a form with coefficients as large as $|\Delta|$ takes $O(\ln|\Delta|)$ steps \cite[Prop.\,5.4.3]{cohen}, each of which involves a bounded number of operations, so for our purposes, reduction has time complexity $O(\ln|\Delta|)$.

    \item Using the binary power algorithm to compute exponents up to $|\Delta|^{1/2}$ involves $O(\ln|\Delta|)$ composition operations \cite[\S\,1.2]{buell}. 
    Composition is just a Euclidean algorithm (or two) combined with a constant number of arithmetic operations.
    As such, its running time is $O(\ln^2|\Delta|)$ per composition \cite[\S\,1.3.1]{cohen}, totalling $O(\ln^3|\Delta|)$.

    \item Computing the order of a form using BSGS involves $O(|\Delta|^{1/4 + \varepsilon})$ composition and hash table operations, which is $O(|\Delta|^{1/4 + \varepsilon})$ arithmetic operations.
    This is the dominant term in our algorithm.
\end{itemize}

We claim that each step which can cause us to restart from the sampling step adds a constant factor to the time complexity.
Although parasitic forms make this uncertain, we assume that our treatment of this issue is effective, and returns us to an inconsequential error term.
This assumption will be supported with evidence shortly.
